# Title:Not all pure entangled states are useful for sub shot-noise interferometry

View PDF HTML (experimental)
            Abstract:  We investigate the usefulness of pure entangled states for sub shot-noise sensitivity of linear interferometers. We consider a fixed particle number N and arbitrary (i) collective and (ii) general local unitary operations which can be applied to the input state. As a measure of the usefulness we use the quantum Fisher information FQ. We show that in case (i) there is a simple way to compute the optimal transformation while in case (ii) an upper bound can be obtained which is tight in many important cases. These results can be directly used to optimize the performance of an interferometer. Using them we show that for N=2 all pure entangled are useful in the sense above while for N>2, there are entangled states which cannot be made useful even in case (ii). Further, we completely characterize all pure symmetric states regarding the usefulness. We compute the optimal FQ for several prominent examples of symmetric states as well as for a non-trivial family of singlet states of an even number of particles and for all cluster states, showing that the latter are practically of no more use than separable states.

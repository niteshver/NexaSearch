# pandas.Timestamp.second#

- Timestamp.second#
- Return the second of the Timestamp. Seconds range from 0 to 59. 
  - Returns:
    - int
    - The second of the Timestamp.
 See also 
  - `Timestamp.microsecond`
  - Return the microsecond of the Timestamp.
  - `Timestamp.minute`
  - Return the minute of the Timestamp.
 Examples >>> ts = pd.Timestamp("2024-08-31 16:16:30") >>> ts.second 30

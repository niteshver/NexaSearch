# pandas.StringDtype.na_value#

- property StringDtype.na_value[source]#
- The missing value representation for this dtype. This value indicates which missing value semantics are used by this dtype. Returns `np.nan` for the default string dtype with NumPy semantics,
and`pd.NA` for the opt-in string dtype with pandas NA semantics.Examples >>> ser = pd.Series(["a", "b"]) >>> ser.dtype <StringDtype(na_value=nan)> >>> ser.dtype.na_value nan

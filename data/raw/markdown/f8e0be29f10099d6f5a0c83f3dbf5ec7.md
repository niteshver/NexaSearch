# pandas.Index.T#

- property Index.T[source]#
- Return the transpose, which is by definition self. See also 
  - `Index`
  - Immutable sequence used for indexing and alignment.
 Examples For Series: >>> s = pd.Series(['Ant', 'Bear', 'Cow']) >>> s 0 Ant 1 Bear 2 Cow dtype: str >>> s.T 0 Ant 1 Bear 2 Cow dtype: str For Index: >>> idx = pd.Index([1, 2, 3]) >>> idx.T Index([1, 2, 3], dtype='int64')

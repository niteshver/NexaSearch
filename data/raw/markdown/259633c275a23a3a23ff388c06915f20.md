#   ⟨49⟩ ClimbMix Split 
`climbmix-split` reorganizes the detokenized NVIDIA ClimbMix source corpus into source-oriented splits. ClimbMix is described as being built from Nemotron-CC and SmolLM-Corpus. Because SmolLM-Corpus is the smaller and directly identifiable component, we used exact normalized-text matching against SmolLM-Corpus to recover the SmolLM-derived portions. The remaining rows are provided as the residual `nemotron-cc` split.
The data rows are unchanged from the detokenized ClimbMix source. Only the shard placement changes.
##   ⟨45⟩ Splits   
| Split  | Rows  | Meaning  |  
| --- | --- | --- |  
| `nemotron-cc`  | 509,811,042  | ClimbMix rows with no exact normalized-text match in the configured SmolLM-Corpus subsets.  |  
| `fineweb-edu-dedup`  | 34,057,577  | Rows exact-matching `HuggingFaceTB/smollm-corpus` config `fineweb-edu-dedup`.  |  
| `cosmopedia-v2`  | 9,139,988  | Rows exact-matching `HuggingFaceTB/smollm-corpus` config `cosmopedia-v2`.  |  
| `python-edu`  | 306,449  | Rows exact-matching `HuggingFaceTB/smollm-corpus` config `python-edu`.  |  
The `nemotron-cc` split is a residual split with respect to this exact-match run. It should not be read as proof that a row has no overlap with any other external corpus.
##   ⟨46⟩ Schema 
Each row is JSONL with:
  * `cluster_id`: integer ClimbMix cluster assignment
  * `text`: detokenized source text
  * `token_count`: source token count from ClimbMix metadata


##   ⟨47⟩ Matching Method 
The split was derived with exact normalized-text matching between ClimbMix rows and the SmolLM-Corpus subsets:
  * `fineweb-edu-dedup`
  * `cosmopedia-v2`
  * `python-edu`


Text was normalized with:
  * Unicode NFKC normalization
  * line-ending normalization
  * trimming at text edges
  * whitespace collapse
  * 128-bit BLAKE2b over normalized UTF-8 text, paired with normalized byte length


`python-edu` text was resolved from the SmolLM metadata using the Software Heritage blob content flow described by the SmolLM-Corpus dataset card.
Rows with a match to exactly one configured SmolLM-Corpus subset were assigned to that source split. Rows with no configured SmolLM-Corpus match were assigned to `nemotron-cc`. The uploaded `metadata/source_membership.parquet` stores one row per matched ClimbMix ID with its matched source membership, primary split label, and multi-source flag.
##   ⟨48⟩ Terms And Provenance 
This dataset is marked as `other` on Hugging Face because the split labels are source-provenance labels, and the relevant upstream terms differ by split. The matched splits expose additional source context from SmolLM-Corpus, FineWeb-Edu, Cosmopedia, and The Stack v2; the residual split remains tied to the ClimbMix/Nemotron-CC source context.
See `LICENSE.md` for the split-specific terms notice and `metadata/source_license_pointers.json` for machine-readable source pointers.

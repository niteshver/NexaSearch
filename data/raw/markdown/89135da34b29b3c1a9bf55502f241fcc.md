# pandas.set_eng_float_format#

- 
pandas.set_eng_float_format(*accuracy=3* ,*use_eng_prefix=False* )[source]#
- Format float representation in DataFrame with SI notation. Deprecated since version 3.1.0: Use `pd.set_option("display.precision", N)` to control decimal
precision, or pass a custom callable to`pd.set_option("display.float_format", func)` .Sets the floating-point display format for `DataFrame` objects using engineering
notation (SI units), allowing easier readability of values across wide ranges.
  - Parameters:
    - **accuracy** int, default 3
    - Number of decimal digits after the floating point.
    - **use_eng_prefix** bool, default False
    - Whether to represent a value with SI prefixes.
  - Returns:
    - None
    - This method does not return a value. it updates the global display format for floats in DataFrames.

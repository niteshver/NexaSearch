# pandas.Interval.open_left#

- Interval.open_left#
- Check if the interval is open on the left side. For the meaning of closed and open see `Interval` .
  - Returns:
    - bool
    - True if the Interval is not closed on the left-side.
 See also 
  - `Interval.open_right`
  - Check if the interval is open on the right side.
  - `Interval.closed_left`
  - Boolean inverse of open_left.
 Examples >>> iv = pd.Interval(0, 5, closed='neither') >>> iv.open_left True >>> iv = pd.Interval(0, 5, closed='both') >>> iv.open_left False

# pandas.DataFrame.pop#

- 
DataFrame.pop(*item* )[source]#
- Return item and drop it from DataFrame. Raise KeyError if not found. 
  - Parameters:
    - **item** label
    - Label of column to be popped.
  - Returns:
    - Series
    - Series representing the item that is dropped.
 See also 
  - `DataFrame.drop`
  - Drop specified labels from rows or columns.
  - `DataFrame.drop_duplicates`
  - Return DataFrame with duplicate rows removed.

("monkey", "mammal", np.nan), ... ], ... columns=("name", "class", "max_speed"), ... ) >>> df name class max_speed 0 falcon bird 389.0 1 parrot bird 24.0 2 lion mammal 80.5 3 monkey mammal NaN >>> df.pop("class") 0 bird 1 bird 2 mammal 3 mammal Name: class, dtype: str >>> df name max_speed 0 falcon 389.0 1 parrot 24.0 2 lion 80.5 3 monkey NaN

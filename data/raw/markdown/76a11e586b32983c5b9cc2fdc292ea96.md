#   ⟨63⟩ Denmark Power Market Data 
Part of a country-split collection of historical electricity market data gathered for the elpriser.org⟨64⟩ price-forecasting project. See the index dataset⟨65⟩ for the other countries: Denmark, Germany, Norway, Sweden, Finland, Netherlands.
##   ⟨54⟩ License & attribution 
CC BY 4.0. EDS files (`eds_*`): Source: Energinet (www.energidataservice.dk⟨66⟩). ENTSO-E files (`entsoe_*`): Source: ENTSO-E Transparency Platform (transparency.entsoe.eu).
##   ⟨55⟩ Contents 
###   ⟨56⟩ EDS (Energinet, Danish TSO) — DK1 (West) and DK2 (East)   
| File  | Description  | Coverage  |  
| --- | --- | --- |  
| `eds_dayaheadprices_dk1/dk2.parquet`  | Day-ahead spot prices (current dataset)  | ~2025-09-30 → present  |  
| `eds_elspotprices_dk1/dk2.parquet`  | Day-ahead spot prices (legacy dataset, longer history)  | 2000-01-01 → 2025-09-30  |  
| `eds_productionconsumptionsettlement_dk1/dk2.parquet`  | Actual generation by source and consumption  | ~2004-12-31 → present  |  
| `eds_datahubpricelist.parquet`  | Nettariffer (every net company's grid tariff), Energinet's own system/transmission tariffs, elafgift (electricity tax), and subscription fees — the full DatahubPricelist price-component list, all charge owners, not split by DK1/DK2 (GLN_Number identifies the charge owner)  | 2014-01-01 → 2027-03-31 (includes announced future tariffs)  |  
###   ⟨57⟩ ENTSO-E — DK1/DK2 direct (complements the EDS files above)   
| File  | Description  |  
| --- | --- |  
| `entsoe_dk1/dk2_load_actual.parquet`  | Actual (realised) total system load, MW  |  
| `entsoe_dk1/dk2_load_forecast.parquet`  | Day-ahead forecast total system load, MW  |  
| `entsoe_dk1/dk2_windsolar_forecast.parquet`  | Day-ahead wind+solar generation forecast (only ~1 day ahead, archived history)  |  
| `entsoe_dk1/dk2_installed_capacity.parquet`  | Installed generation capacity per type, yearly snapshots  |  
###   ⟨58⟩ Interconnector data (Denmark's actual physical borders)   
| File pattern  | Pairs covered  |  
| --- | --- |  
| `entsoe_flow_{pair}.parquet`  | Actual physical cross-border flow (MW), both directions  |  
| `entsoe_ntc_{pair}.parquet`  | Day-ahead estimated Net Transfer Capacity (MW), both directions — sparse/empty for pure Nordic-Nordic borders (dk1_no2, dk1_se3, dk2_se4), which use flow-based (JAO) capacity allocation instead  |  
Pairs: `dk1_delu`, `dk1_no2`, `dk1_se3`, `dk1_nl`, `dk2_delu`, `dk2_se4`.
##   ⟨59⟩ Note on `eds_datahubpricelist.parquet`
Columns include `ChargeOwner`, `GLN_Number`, `ChargeType` (D01 subscription, D02 fee, D03 tariff), `Note`/`Description`, `ValidFrom`/`ValidTo`, `VATClass`, `Price1`–`Price24` (hourly for `ResolutionDuration=PT1H` tariffs, single monthly/yearly value otherwise), and `ResolutionDuration`. To reconstruct "nettarif C" for a specific net company, filter `ChargeType == "D03"` and `Note == "Nettarif C"` for that company's `GLN_Number`; Energinet's own system/transmission tariffs and elafgift are under `GLN_Number = "5790000432752"`.
##   ⟨60⟩ Note on Nordic flow-based congestion data 
JAO's Nordic flow-based market coupling data (PTDF/shadow-price congestion data) is **not** included here or anywhere in this collection — JAO's terms of use prohibit redistribution without prior written authorization. If you want it, register for a free personal token at publicationtool.jao.eu⟨67⟩.
##   ⟨61⟩ Format 
Parquet, one row per timestamp (and per production type / charge line, where applicable). Column names are preserved as returned by the source API.
##   ⟨62⟩ Provenance 
Collected 2026-07-03/04 (prices/production/interconnectors) and 2026-07-10 (tariffs/charges) via each provider's public API using free, personally-registered access. Collection scripts: elpriser.org repo⟨68⟩, `scripts/data_backup/`.

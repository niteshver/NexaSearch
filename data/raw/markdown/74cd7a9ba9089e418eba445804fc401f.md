# pandas.Timedelta.to_numpy#

- 
Timedelta.to_numpy(*dtype=None* ,*copy=False* )#
- Convert the Timedelta to a NumPy timedelta64. This is an alias method for Timedelta.to_timedelta64(). 
  - Parameters:
    - **dtype** NoneType
    - It is available here only for compatibility. Its value will not affect the return value.
    - **copy** bool, default False
    - It is available here only for compatibility. Its value will not affect the return value.
  - Returns:
    - numpy.timedelta64
 See also 
  - `Series.to_numpy`
  - Similar method for Series.
 Examples >>> td = pd.Timedelta('3D') >>> td Timedelta('3 days 00:00:00') >>> td.to_numpy() np.timedelta64(259200000000,'us')

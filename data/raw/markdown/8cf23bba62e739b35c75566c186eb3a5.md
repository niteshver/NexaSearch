#   ⟨63⟩ SpanUQ Benchmark 
A span-level uncertainty estimation benchmark for large language model generation. Each example contains an LLM-generated response decomposed into **spans** (contiguous text segments expressing single verifiable assertions), with **uncertainty labels** derived from sampling-based consistency verification.
##   ⟨55⟩ Quick Start 

```
from datasets import load_dataset

# Load a specific model configuration
ds = load_dataset("DamonDemon/SpanUQ-Benchmark", "Qwen3-14B")
print(ds["test"][0])

```

| `uncertainty`  | `float`  | Span uncertainty score ∈ [0, 1] (0 = confident/correct, 1 = uncertain/hallucinated)  |  
##   ⟨58⟩ Annotation Pipeline 
  1. **Response Generation** : Greedy decoding from each LLM
  2. **Span Extraction** : Decompose responses into spans, each expressing a single verifiable assertion
  3. **Claim Extraction** : Convert each span into a self-contained factual claim
  4. **Sampling** : Generate 20 stochastic responses per query (temperature sampling)
  5. **Consistency Verification** : Use an LLM judge to verify each claim against each sampled response
  6. **Uncertainty Scoring** : `uncertainty = 1 − (supported_count / total_verified_count)`


##   ⟨59⟩ Intended Use 
  * **Training and evaluating** span-level uncertainty estimation models
  * **Benchmarking** hallucination detection at sub-sentence granularity
  * **Studying** uncertainty patterns across different LLM architectures and scales

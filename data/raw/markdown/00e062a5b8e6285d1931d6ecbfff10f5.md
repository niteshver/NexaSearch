#   ⟨158⟩ Dataset Card for OpenITI MAKHZAN Ottoman Lines 
###   ⟨159⟩ Dataset Summary 
This dataset contains line-level image-text pairs of historical Ottoman Turkish manuscripts and printed documents. It is derived from the **OpenITI MAKHZAN** dataset, a large aggregation of Arabic-script ground truth and evaluation data developed by the Open Islamicate Texts Initiative (OpenITI). The dataset specifically focuses on Ottoman Turkish texts and is highly valuable for training and evaluating Optical Character Recognition (OCR), Handwritten Text Recognition (HTR), and Vision-Language Models (VLM). It includes documents predominantly written in the **Naskh** script style (approx. 95%), offering an excellent resource for cross-style and out-of-distribution evaluation of historical document recognition systems.
###   ⟨160⟩ Supported Tasks and Leaderboards 
  * `image-to-text`: This dataset is primarily designed for Handwritten Text Recognition (HTR) and Optical Character Recognition (OCR) tasks. Models are trained to transcribe the Ottoman Turkish text present in the line-level images.


###   ⟨161⟩ Languages 
The text in the dataset is in **Ottoman Turkish** written in the Arabic script.
##   ⟨156⟩ Dataset Structure 
###   ⟨157⟩ Data Instances 
Each data instance consists of an image of a text line and its corresponding ground-truth transcription.

```
{
  "image": "<PIL.PngImagePlugin.PngImageFile image mode=RGB size=1024x128 at 0x...>",
  "text": "مسافر خانه در بلدك جهاني برايكى كونسن انجق مهماني"
}
Data Fields
image: A PIL Image object containing the cropped line of text.
text: A string containing the transcribed Ottoman Turkish text.
Data Splits
The dataset is divided into two splits:

train: Contains the majority of the line-level samples (3,512 lines) used for model training.
test: Contains 142 out-of-distribution (OOD) examples, predominantly in the Naskh script style, specifically curated for evaluating model robustness and cross-style generalization.
Dataset Creation
Source Data
The data originates from the OpenITI MAKHZAN project. The Open Islamicate Texts Initiative (OpenITI) was founded in 2017 to build digital infrastructure for the study of the premodern Islamic world. The MAKHZAN dataset addresses the historical underperformance of OCR/HTR for Arabic-script languages by providing a robust aggregation of ground truth data for languages such as Persian, Arabic, Ottoman Turkish, and Urdu.

Initial Data Collection and Normalization
Images were extracted from various historical manuscripts and printed books, segmented into line-level pairs, and transcribed by experts within the OpenITI ecosystem.

This dataset is released under the same open-access terms as the original OpenITI MAKHZAN dataset. Please refer to the Zenodo repository for exact licensing details.
```

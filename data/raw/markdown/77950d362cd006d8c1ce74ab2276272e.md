# pandas.errors.DatabaseError#

- exception pandas.errors.DatabaseError[source]#
- Error is raised when executing SQL with bad syntax or SQL that throws an error. Raised by `pandas.read_sql()` when a bad SQL statement is passed in.See also 
  - `read_sql`
  - Read SQL query or database table into a DataFrame.
 Examples >>> from sqlite3 import connect >>> conn = connect(":memory:") >>> pd.read_sql("select * test", conn)

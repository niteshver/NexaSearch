#   ⟨102⟩ PBR Materials (MonoRelief V2 core) 
Auto-generated PBR material set (10 materials). Each subfolder contains a complete PBR set:  
| Map  | File  | Format  |  
| --- | --- | --- |  
| Albedo  | `*_albedo.png`  | 8-bit RGB  |  
| Height  | `*_height.png`  | 16-bit grayscale  |  
| Normal  | `*_normal.png`  | 8-bit RGB (OpenGL, Godot 4)  |  
| Roughness  | `*_roughness.png`  | 8-bit grayscale  |  
| Metallic  | `*_metallic.png`  | 8-bit grayscale  |  
##   ⟨99⟩ Pipeline 
Generated using MonoRelief V2 (Fig. 7), Marigold-only variant:
  1. Base depth — **Marigold Depth** v1.0
  2. Normals — **Marigold Normals** v0.1
  3. Scharr-from-depth + Marigold normals → geometric fusion
  4. BiNI (Bilateral Normal Integration) → refined depth
  5. Frequency blend (Marigold Depth low-freq + BiNI high-freq, edge-suppressed)
  6. PBR maps derived: height from final depth; roughness + metallic from heuristics

##   ⟨101⟩ Godot 4 import 
  1. Create `StandardMaterial3D`.
  2. Set **Albedo → Texture** to `*_albedo.png`.
  3. Set **Normal Map → Texture** to `*_normal.png` (enable `Normal Map` toggle).
  4. Set **Roughness → Texture** to `*_roughness.png` (Mode = R).
  5. Set **Metallic → Texture** to `*_metallic.png` (Mode = R).
  6. Optional: **Depth → Texture** = `*_height.png` for parallax/displacement.

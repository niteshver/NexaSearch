#   ⟨37⟩ Board Generator Knot Sequence Model 
This repository contains the trained knot sequence generator used by the Board Generator demo.
Files:
  * `knot_sequence_model.pt`: original PyTorch LSTM checkpoint.
  * `knot_sequence_model.npz`: NumPy-exported LSTM checkpoint used by the CPU Hugging Face Space.
  * `knot_sequence_model.json`: metadata for the trained knot sequence model.
  * `training_data_new_2025.mat`: knot dictionary and tokenized sequence data used by Board Generator to map sampled tokens to knot parameters.


The model generates stochastic knot-token sequences. Board Generator then maps those tokens to geometric knot parameters for synthetic log, board, and veneer generation. Downloads last month

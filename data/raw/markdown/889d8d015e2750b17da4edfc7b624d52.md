# pandas.tseries.offsets.QuarterBegin.copy#

- QuarterBegin.copy()#
- Return a copy of the frequency. This method creates a new instance of the same frequency offset with identical parameters. The returned copy is independent of the original, allowing modifications without affecting the source object. See also 
  - `tseries.offsets.Week.copy`
  - Return a copy of Week offset.
  - `tseries.offsets.DateOffset.copy`
  - Return a copy of date offset.
  - `tseries.offsets.MonthEnd.copy`
  - Return a copy of MonthEnd offset.
  - `tseries.offsets.YearBegin.copy`
  - Return a copy of YearBegin offset.

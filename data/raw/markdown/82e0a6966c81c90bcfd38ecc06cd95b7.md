# pandas.Index.drop#

- 
Index.drop(*labels* ,*errors='raise'* )[source]#
- Make new Index with passed list of labels deleted. Unlike `Index.delete()` , which accepts positional indices, this
method removes entries by their label values. The original Index is
not modified.
  - Parameters:
    - **labels** array-like or scalar
    - Array-like object or a scalar value, representing the labels to be removed from the Index.
    - **errors** {‘ignore’, ‘raise’}, default ‘raise’
    - If ‘ignore’, suppress error and existing labels are dropped.
  - Returns:
    - Index
    - Will be same type as self, except for RangeIndex.
  - Raises:
    - KeyError
    - If not all of the labels are found in the selected axis
 See also 
  - `Index.dropna`
  - Return Index without NA/NaN values.
  - `Index.drop_duplicates`
  - Return Index with duplicate values removed.
 Examples >>> idx = pd.Index(["a", "b", "c"]) >>> idx.drop(["a"]) Index(['b', 'c'], dtype='str')

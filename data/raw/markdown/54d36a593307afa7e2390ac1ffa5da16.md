# pandas.Index.dtype#

- Index.dtype[source]#
- Return the dtype object of the underlying data. The dtype describes the type of elements stored in the Index, such as `int64` ,`float64` ,`object` , or an extension dtype.See also 
  - `Index.inferred_type`
  - Return a string of the type inferred from the values.
 Examples >>> idx = pd.Index([1, 2, 3]) >>> idx Index([1, 2, 3], dtype='int64') >>> idx.dtype dtype('int64')

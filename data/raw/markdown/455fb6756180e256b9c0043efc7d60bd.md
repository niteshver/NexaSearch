# pandas.api.extensions.ExtensionArray.astype#

- 
ExtensionArray.astype(*dtype* ,*copy=True* )[source]#
- Cast to a NumPy array or ExtensionArray with ‘dtype’. If the target dtype is an ExtensionDtype, the result is an ExtensionArray. Otherwise, the result is a NumPy ndarray. 
  - Parameters:
    - **dtype** str or dtype
    - Typecode or data-type to which the array is cast.
    - **copy** bool, default True
    - Whether to copy the data, even if not necessary. If False, a copy is made only if the old dtype does not match the new dtype.
  - Returns:
    - np.ndarray or pandas.api.extensions.ExtensionArray
    - An `ExtensionArray` if`dtype` is`ExtensionDtype` ,
otherwise a Numpy ndarray with`dtype` for its dtype.

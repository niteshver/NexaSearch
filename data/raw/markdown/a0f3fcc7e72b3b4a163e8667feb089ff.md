# pandas.Timestamp.day#

- Timestamp.day#
- Return the day of the Timestamp. Days are numbered from 1 through the number of days in the month. 
  - Returns:
    - int
    - The day of the Timestamp.
 See also 
  - `Timestamp.week`
  - Return the week number of the year.
  - `Timestamp.weekday`
  - Return the day of the week.
 Examples >>> ts = pd.Timestamp("2024-08-31 16:16:30") >>> ts.day 31

# pandas.Timestamp.minute#

- Timestamp.minute#
- Return the minute of the Timestamp. Minutes range from 0 through 59. 
  - Returns:
    - int
    - The minute of the Timestamp.
 See also 
  - `Timestamp.hour`
  - Return the hour of the Timestamp.
  - `Timestamp.second`
  - Return the second of the Timestamp.
 Examples >>> ts = pd.Timestamp("2024-08-31 16:16:30") >>> ts.minute 16

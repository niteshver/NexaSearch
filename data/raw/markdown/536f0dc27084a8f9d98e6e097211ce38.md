# pandas.Timestamp.fold#

- Timestamp.fold#
- Return the fold value of the Timestamp. The fold attribute is used to disambiguate wall times in a repeated interval during daylight saving time transitions. 
  - Returns:
    - int
    - The fold value of the Timestamp, where 0 indicates the first occurrence of the ambiguous time, and 1 indicates the second.
 See also 
  - `Timestamp.dst`
  - Return the daylight saving time (DST) adjustment.
  - `Timestamp.tzinfo`
  - Return the timezone information associated.
 Examples >>> ts = pd.Timestamp("2024-11-03 01:30:00") >>> ts.fold 0

# pandas.Timestamp.is_year_end#

- Timestamp.is_year_end#
- Return True if date is last day of the year. This is determined by checking whether the month is 12 and the day is 31 (i.e., December 31st). 
  - Returns:
    - bool
 See also 
  - `Timestamp.is_year_start`
  - Similar property indicating the start of the year.
 Examples >>> ts = pd.Timestamp(2020, 3, 14) >>> ts.is_year_end False >>> ts = pd.Timestamp(2020, 12, 31) >>> ts.is_year_end True

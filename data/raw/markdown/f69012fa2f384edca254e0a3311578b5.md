# `sklearn.metrics.pairwise`.rbf_kernel¶

- 
`sklearn.metrics.pairwise.``rbf_kernel` (*X* ,*Y=None* ,*gamma=None* )[source]¶
- Compute the rbf (gaussian) kernel between X and Y: K(x, y) = exp(-gamma ||x-y||^2) for each pair of rows x in X and y in Y. Parameters: **X** : array of shape (n_samples_X, n_features)**Y** : array of shape (n_samples_Y, n_features)**gamma** : floatReturns: **kernel_matrix** : array of shape (n_samples_X, n_samples_Y)

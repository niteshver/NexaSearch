#   ⟨67⟩ 🧬 Pharmaceutical Knowledge Graph (ATC + Biomedical Entities) 
##   ⟨36⟩ 📌 Overview 
This project builds a **pharmaceutical knowledge graph** that connects drugs classified under the **ATC (Anatomical Therapeutic Chemical) system** to a wide range of biomedical entities extracted from text using Named Entity Recognition (NER).
The goal is to support:
  * 🔬 Biomedical reasoning 
  * 💊 Drug–disease exploration 
  * 🤖 Graph-based machine learning 
  * 🧠 Downstream AI systems (GraphRAG / LLM augmentation)


* * *
##   ⟨37⟩ 🌳 Graph Structure 
The knowledge graph consists of two integrated layers:
* * *
##   ⟨38⟩ 💊 1. ATC Drug Classification System 
Drugs are structured using the ATC hierarchy:
  * 🟢 **Level 1:** Anatomical main group 
  * 🔵 **Level 2:** Therapeutic subgroup 
  * 🟡 **Level 3:** Pharmacological subgroup 
  * 🟠 **Level 4:** Chemical subgroup 
  * 🔴 **Level 5:** Chemical substance (specific drug)


Each drug node is represented as: TREATMENT_ 📌 Example:TREATMENT_a10ba02 The knowledge graph is made up of several layers.
* * *
##   ⟨39⟩ 🧪 2. Biomedical Entity Layer 
Biomedical entities extracted using NER include:
  * 🦠 Diseases & conditions 
  * 🧬 Genes & gene products 
  * 🧫 Cells & cellular components 
  * 🫀 Organs & tissues 
  * 🧍 Organisms (including humans) 
  * ⚗️ Chemicals & simple chemicals 
  * 🧪 Organism substances 
  * ⚠️ Pathological formations


* * *
##   ⟨40⟩ 🔗 3. Relationship Types 
Edges represent biomedical and structural relationships:
  * 💊 **TREATS** → Drug → Disease / Condition 
  * 🎯 **TARGETS** → Drug → Organ / Cancer / Molecular target 
  * 🚫 **INHIBITS** → Drug → Organism / biological activity 
  * 🧪 **CONSISTS_OF** → Drug → Chemical components 
  * 👤 **INDICATED_FOR** → Drug → Human use context 
  * 🔗 **ASSOCIATED_WITH** → General NER-based relationship 
  * 🌳 **HAS_CHILD** → ATC structure


* * *

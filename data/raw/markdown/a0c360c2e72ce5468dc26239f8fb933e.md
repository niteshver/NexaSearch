# pandas.CategoricalDtype.ordered#

- property CategoricalDtype.ordered[source]#
- Whether the categories have an ordered relationship. See also 
  - `categories`
  - An Index containing the unique categories allowed.
 Examples >>> cat_type = pd.CategoricalDtype(categories=["a", "b"], ordered=True) >>> cat_type.ordered True >>> cat_type = pd.CategoricalDtype(categories=["a", "b"], ordered=False) >>> cat_type.ordered False

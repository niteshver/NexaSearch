    # Title:Four-qubit entanglement from string theory

View PDF HTML (experimental)
            Abstract:We invoke the black hole/qubit correspondence to derive the classification of four-qubit entanglement. The U-duality orbits resulting from timelike reduction of string theory from D=4 to D=3 yield 31 entanglement families, which reduce to nine up to permutation of the four qubits.

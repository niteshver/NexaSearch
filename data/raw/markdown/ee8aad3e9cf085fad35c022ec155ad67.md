  * `faithful_bonus = 1` if all numbers and named entities from the source are preserved
  * `flesch_grade` = Flesch-Kincaid grade level (lower = simpler)
  * `jargon_count` = count of finance-domain jargon terms


**Rejected rewrite** : One of four degradation types cycled across examples:
  * `over_formal` — rewritten with formal register and longer sentences
  * `jargon_padded` — original jargon terms preserved or added
  * `literal` — near-literal restatement without simplification
  * `verbose` — correct content but padded with unnecessary words


**Split** : 80 / 10 / 10 (train / valid / test), shuffled with seed 0.
##   ⟨56⟩ Intended Use 
Fine-tune a 7B instruction model (e.g. `Qwen2.5-7B-Instruct`) on the SFT split first, then apply DPO with the SFT model as frozen reference. This trains the model to prefer simpler rewrites without sacrificing factual accuracy.
The companion fine-tuned model is available at Akshat4112/FinPlainLM⟨64⟩.
##   ⟨57⟩ Limitations 
  * **Domain narrow** : Source sentences are from Financial PhraseBank, which covers short news-wire snippets. Performance on longer documents, earnings calls, or regulatory filings has not been evaluated.
  * **Teacher model bias** : Chosen rewrites were generated by `Qwen2.5-14B-Instruct`. Any stylistic biases of that model are inherited by this dataset.
  * **Rejected quality** : Rejected rewrites are synthetically degraded, not naturally occurring bad rewrites. Real-world bad rewrites may differ in character.
  * **English only** : All sentences are in English. The model trained on this data should not be expected to generalize to other languages.
  * **Non-commercial only** : CC BY-NC-SA 3.0 license prohibits commercial use.


##   ⟨58⟩ Ethical Considerations 
  * **Factual accuracy** : The chosen rewrite heuristic penalises loss of numbers and named entities, but does not guarantee factual correctness. Always verify model outputs before using in client-facing communications.
  * **Financial advice** : This dataset is for text simplification only. Nothing in it constitutes financial advice, and models trained on it should not be deployed as financial advisors.
  * **Source license compliance** : Financial PhraseBank is CC BY-NC-SA 3.0. This dataset inherits that license; any derivative work must do the same.

##   ⟨57⟩ Schema 
###   ⟨58⟩ documents 
  * `id`: stable document id used by `queries.relevant_document_ids`
  * `domain`: `financial` or `medical`
  * `source`: source-family description
  * `source_path`: original PEARL relative path
  * `document_id`: original source document id or source group id
  * `group_id`: topic/file group id
  * `chunk_id`: chunk index where available
  * `title`: markdown heading when available
  * `text`: cleaned document text
  * `char_count`, `word_count`: basic text statistics
  * `contains_synthetic_phi_or_pii`: whether the record contains synthetic private information


###   ⟨59⟩ queries 
  * `id`: stable query id
  * `domain`: `financial` or `medical`
  * `source_record_id`: original index id
  * `query_index`: query index within the original source record
  * `query`: cleaned user/patient question
  * `answer`: reference answer
  * `relevant_document_ids`: document ids linked to the query
  * `source_paths`: original PEARL relative paths linked to the query
  * `privacy_spans`: source-provided privacy spans when available
  * `rank`: source-provided rank annotations when available
  * `contains_synthetic_phi_or_pii`: whether the record contains synthetic private information

##   ⟨61⟩ Processing Notes 
  * Included domains: `financial`, `medical`
  * Excluded domains: `legal`
  * Only index-referenced markdown files are included.
  * Common mojibake artifacts were repaired where detectable.
  * Line endings were normalized to LF and surrounding whitespace was stripped.
  * No train/test split is created because the original PEARL subset does not define one.
  * Text may contain synthetic PHI/PII by design; review dataset visibility before publishing.

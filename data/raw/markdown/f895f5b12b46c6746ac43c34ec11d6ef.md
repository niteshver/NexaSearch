# pandas.errors.DataError#

- exception pandas.errors.DataError[source]#
- Exception raised when performing an operation on non-numerical data. For example, calling `ohlc` on a non-numerical column or a function
on a rolling window.See also 
  - `Series.rolling`
  - Provide rolling window calculations on Series object.
  - `DataFrame.rolling`
  - Provide rolling window calculations on DataFrame object.

# pandas.tseries.offsets.QuarterEnd.normalize#

- QuarterEnd.normalize#
- Return boolean whether the frequency can align with midnight. This is True for offsets that round the result of a DateOffset addition down to the previous midnight. See also 
  - `tseries.offsets.DateOffset`
  - The standard kind of date increment.
 Examples >>> pd.offsets.Hour(5).normalize False >>> pd.offsets.Day(5).normalize False

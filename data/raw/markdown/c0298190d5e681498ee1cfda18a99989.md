# `sklearn.datasets`.load_sample_images¶

- 
`sklearn.datasets.``load_sample_images` ()[source]¶
- Load sample images for image manipulation. Loads both, `china` and`flower` .Returns: **data** : BunchDictionary-like object with the following attributes : ‘images’, the two sample images, ‘filenames’, the file names for the images, and ‘DESCR’ the full description of the dataset. Examples To load the data and visualize the images: >>> from sklearn.datasets import load_sample_images >>> dataset = load_sample_images() >>> len(dataset.images) 2 >>> first_img_data = dataset.images[0] >>> first_img_data.shape (427, 640, 3) >>> first_img_data.dtype dtype('uint8')

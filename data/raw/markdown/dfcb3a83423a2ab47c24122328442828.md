# pandas.Series.std#

- 
Series.std(*** ,*axis=None* ,*skipna=True* ,*ddof=1* ,*numeric_only=False* ,***kwargs* )[source]#
- Return sample standard deviation. Normalized by N-1 by default. This can be changed using the ddof argument. 
  - Parameters:
    - **axis** {index (0)}
    - This parameter is unused and defaults to 0.
    - **skipna** bool, default True
    - Exclude NA/null values. If Series is NA, the result will be NA.
    - **ddof** int, default 1
    - Delta Degrees of Freedom. The divisor used in calculations is N - ddof, where N represents the number of elements.
    - **numeric_only** bool, default False
    - Not implemented for Series.
    - ****kwargs**
    - Additional keywords have no effect but might be accepted for compatibility with NumPy. See NumPy compatibility kwargs for more.
  - Returns:
    - scalar
    - Standard deviation over all values in the Series.

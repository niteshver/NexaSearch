#   ⟨39⟩ Nordic & Western European Power Market Data 
This collection has been split into one dataset per country for easier browsing and download. This repo is now just an index — the actual data files live here:
  * **Denmark⟨40⟩** — EDS (Energinet) day-ahead prices + production/consumption back to 2000, plus ENTSO-E load/capacity/interconnector data
  * **Germany⟨41⟩** — DE-LU zone, prices/generation/load/capacity
  * **Norway⟨42⟩** — all 5 bidding zones (NO1–NO5)
  * **Sweden⟨43⟩** — all 4 bidding zones (SE1–SE4)
  * **Finland⟨44⟩** — FI zone
  * **Netherlands⟨45⟩** — NL zone


All data is **CC BY 4.0** (Energinet / ENTSO-E Transparency Platform — see each dataset's README for exact attribution). JAO's Nordic flow-based congestion data is deliberately not included anywhere in this collection — their terms prohibit redistribution without prior written authorization.
Collected for the elpriser.org⟨46⟩ price-forecasting project. Collection scripts: elpriser.org repo⟨47⟩, `scripts/data_backup/`.

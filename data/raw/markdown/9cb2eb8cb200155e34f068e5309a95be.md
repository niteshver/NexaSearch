# pandas.Index.is_interval#

- 
*final* Index.is_interval()[source]#
- Check if the Index holds Interval objects. Deprecated since version 2.0.0: Use isinstance(index.dtype, pd.IntervalDtype) instead. 
  - Returns
    - bool
    - Whether or not the Index holds Interval objects.

# pandas.HDFStore.get#

- 
HDFStore.get(*key* )[source]#
- Retrieve pandas object stored in file. The object is read from the HDF5 file and returned as the same type that was stored (e.g., DataFrame, Series). 
  - Parameters:
    - **key** str
    - Object to retrieve from file. Raises KeyError if not found.
  - Returns:
    - object
    - Same type as object stored in file.
 See also 
  - `HDFStore.get_node`
  - Returns the node with the key.
  - `HDFStore.get_storer`
  - Returns the storer object for a key.
 Examples >>> df = pd.DataFrame([[1, 2], [3, 4]], columns=["A", "B"]) >>> store = pd.HDFStore("store.h5", "w") >>> store.put("data", df) >>> store.get("data") >>> store.close()

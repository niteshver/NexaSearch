# pandas.Timestamp.asm8#

- Timestamp.asm8#
- Return numpy datetime64 format with same precision. This property provides interoperability with NumPy datetime operations. See also 
  - `numpy.datetime64`
  - Numpy datatype for dates and times with high precision.
  - `Timestamp.to_numpy`
  - Convert the Timestamp to a NumPy datetime64.
  - `to_datetime`
  - Convert argument to datetime.
 Examples >>> ts = pd.Timestamp(2020, 3, 14, 15) >>> ts.asm8 np.datetime64('2020-03-14T15:00:00.000000')

# pandas.Timestamp.utctimetuple#

- Timestamp.utctimetuple()#
- Return UTC time tuple, compatible with time.localtime(). This method converts the Timestamp to UTC and returns a time tuple containing 9 components: year, month, day, hour, minute, second, weekday, day of year, and DST flag. This is particularly useful for converting a Timestamp to a format compatible with time module functions. 
  - Returns:
    - time.struct_time
    - A time.struct_time object representing the UTC time.
 See also 
  - `datetime.datetime.utctimetuple`
  - Return UTC time tuple, compatible with time.localtime().
  - `Timestamp.timetuple`
  - Return time tuple of local time.
  - `time.struct_time`
  - Time tuple structure used by time functions.

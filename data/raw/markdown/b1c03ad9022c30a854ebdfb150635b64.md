#   ⟨47⟩ tool-failure-recovery-trajectories 
Training data + full evaluation transcripts from the **QUENCH** study (_do trained agentic skills survive 4-bit quantization?_). Companion to `qwen3-8b-tool-recovery`⟨48⟩.
##   ⟨44⟩ Contents 
**`train/recovery_v3.jsonl`**— 682 synthetic training trajectories (`messages` + `tools` + `metadata`):
  * 480 recovery trajectories: 4 strategies (retry / switch to alternative tool / ask user / honest failure after 2nd attempt) × 3 failure types (error / malformed / timeout) × 8 tool domains, with proper `tool_calls` structure and `tool` roles.
  * 152 plain tool-success trajectories (protects tool-calling under SFT).
  * 50 no-tool examples (prevents tool over-triggering).


**`train/recovery_v3_rendered.jsonl`**— the same data rendered through the Qwen3 chat template with the empty-`<think>` -block normalization applied to every assistant span (the exact `text` field used for training; see the think-block asymmetry note in the model card).
**`eval/gen_*.json`**— full per-trial transcripts for all 7 grid cells (~1,260 trials): injected failure, complete post-failure trajectory (including retry tool calls and simulated results), heuristic rubric, and verdicts from**both** judges (GLM-5.2 as `judge`, gemma-4-12b as `judge_gemma`) with reasoning strings.
**`eval/grid_v3.md`/`grid_v3.json`** — final analysis: bootstrap CIs, paired deltas, cross-judge agreement.
##   ⟨45⟩ Provenance & contamination controls 
  * Training data is fully **programmatic/synthetic** (no LLM-generated text, no API teachers) — licensing is clean Apache-2.0.
  * Training failure texts are **disjoint** from eval injected-failure texts (no surface-form leakage).
  * Eval tasks: 60 stratified BFCL v3 single-turn tasks; the quantization calibration set was drawn from a **non-overlapping** BFCL pool.


##   ⟨46⟩ Intended use 
Reproducing/extending QUENCH; training small models for tool-failure recovery; studying LLM-judge criterion sensitivity (the dual-judge transcripts show a clean behavioral-vs-faithfulness disagreement pattern on "recovered but invented specifics" trials).

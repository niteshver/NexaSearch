# pandas.arrays.TimedeltaArray#

- 
class pandas.arrays.TimedeltaArray(*data* ,*dtype=None* ,*freq=None* ,*copy=False* )[source]#
- Pandas ExtensionArray for timedelta data. Warning TimedeltaArray is currently experimental, and its API may change without warning. In particular, `TimedeltaArray.dtype` is
expected to change to be an instance of an`ExtensionDtype` subclass.
  - Parameters:
    - **data** array-like
    - The timedelta data.
    - **dtype** numpy.dtype
    - Valid `numpy` dtypes are`timedelta64[ns]` ,`timedelta64[us]` ,`timedelta64[ms]` , and`timedelta64[s]` .
    - **freq** Offset, optional
    - Frequency of the data.
    - **copy** bool, default False
    - Whether to copy the underlying array of data.

#   ⟨50⟩ README 
This dataset consists of 123 industrial-grade large-format lithium-ion pouch cells released with the Nature article **Discovery Learning predicts battery cycle life from minimal experiments**. The article describes these cells as having diverse material-design combinations and cycling protocols. The source data are available from Zenodo and Code Ocean through the article's Data availability section.
The local processed directory contains 123 `.pkl` files, one file per cell. File names preserve the original Farasis cell id and source parquet path, for example:

```
Farasis_PB-b1_2_MP_029_single_parquet_with_soc_and_corrections_updated.pkl

```

If you use this dataset, please cite the original paper:
  * **Discovery Learning predicts battery cycle life from minimal experiments** _2026 Nature_

##   ⟨43⟩ Source Data 
The original dataset is available at:
  * Nature article: <https://www.nature.com/articles/s41586-025-09951-7>
  * Zenodo: <https://doi.org/10.5281/zenodo.17654407>
  * Code Ocean: <https://doi.org/10.24433/CO.5569470.v1>


The Nature article states that the study data contain 123 large-format lithium-ion pouch cells. The Zenodo record contains these files:
  * `raw_data.zip`
  * `rpt_data.zip`
  * `number_relationship.xlsx`
  * `readme.txt`
  * `Parquet_analysis.py`


The Zenodo `readme.txt` describes the source dataset as RPT `.xlsx` files and raw `.parquet` files for eight battery cell types. It states that the parquet files contain current, voltage, temperature, and other cycling information recorded at one-second resolution. It also states that `number_relationship.xlsx` maps 123 cells to 37 cell groups and records the cycle-life labels.

##   ⟨48⟩ Labels 
Label JSON files for this dataset are stored in `datasets/processed/`:
  * `Farasis_labels.json`: author-provided labels transcribed from the source label table and keyed by processed Farasis file name in id order.
  * `repro_Farasis_labels.json`: locally recalculated 90% SOH EFC labels based on the processed/raw Farasis data. The current local recalculation uses the cumulative discharge throughput column when available.

/square6Usually calculated cross-system 
/circle6Final scores of every evaluated system are correlat ed with fluency or 
with adequacy scores 
/square6Small number of sample points 
/square6Global result for an evaluation 
/square6Our approach: compute a form of correlation for each system 
/circle6Use bootstrapping to generate a large number of sam ple points 
/square6Artificially generate several samples for each syst em 
/circle6Hypothesis

Bootstrapping algorithm 
/square6Statistical method to infer estimators of a variable 
/circle6in MT used for statistical significance tests (Koeh n 
2004) ; in ASR to estimate c.i. (Bisani & Ney 2004)
/square6Advantages 
/circle6Applicable to one (or more) system(s) 
/circle6Individual results for each system 
/square6Disadvantage 
/circle6direct comparison with standard correlation not possible P. Estrella, A. Popescu-Belis, M. King -ISSCO/TIM/E TI -University of Geneva 6/23 
Bootstrapping algorithm (II) 
/square6Given a corpus (set of texts) with Nsegments 
1. Generate a new corpus with Nsegments randomly selected 
/circle6Segments can appear 0 or more times 
2. Apply metrics on the new (= artificial, bootstrappe d) corpus 
3. Repeat 1,500 times 
4. Calculate correlation over 1,500 scores 
/square6For consistency of Pearson’s Rcoefficients 
/circle6Metrics applied at system level
/circle6Random numbers fixed for all metrics 
/square6Output: correlation matrixes per system, 
for any pair of evaluation metrics P. Estrella, A. Popescu-Belis, M. King -ISSCO/TIM/E TI -University of Geneva 7/23

# pandas.Interval.right#

- Interval.right#
- Right bound for the interval. The right endpoint of the interval. Whether it is included in the interval depends on the value of `closed` .See also 
  - `Interval.left`
  - Return the left bound for the interval.
  - `numpy.ndarray.right`
  - A similar method in numpy for obtaining the right endpoint(s) of intervals.
 Examples >>> interval = pd.Interval(left=1, right=2, closed='left') >>> interval Interval(1, 2, closed='left') >>> interval.right 2

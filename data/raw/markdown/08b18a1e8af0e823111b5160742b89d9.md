# pandas.tseries.offsets.BusinessHour.n#

- BusinessHour.n#
- Return the count of the number of periods. This represents how many multiples of the offset frequency should be applied. For example, `Hour(5)` has`n=5` .See also 
  - `DateOffset.normalize`
  - Return boolean whether the frequency can align with midnight.
 Examples >>> pd.offsets.Hour(5).n 5 >>> pd.offsets.Day(3).n 3

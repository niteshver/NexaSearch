#   ⟨56⟩ PDB-Monomeric-Structure-ESMFold2 
Monomeric, protein-only PDB structure dataset for minimum ESMFold2-style training. Each row is one eligible single-chain biological assembly with a canonical amino-acid sequence input and all-atom protein labels in `atom37`.
##   ⟨49⟩ Labels 
  * `atom37_positions`: residue x 37 x 3 coordinates, with zeros for missing atoms.
  * `atom37_mask`: residue x 37 resolved-atom mask.
  * `aatype`, `residue_index`, `auth_seq_id`, `insertion_code`, `residue_name`, `ca_mask`.
  * Experiment metadata: `resolution`, `r_work`, `r_free`, `method`, `release_date`.


##   ⟨50⟩ Scope 
The dataset is PDB-only and protein-only. Ligands, waters, ions, nucleic acids, unsupported atoms, MSAs, ligand bonds, nucleotide fields, and AFDB distillation rows are not included.
##   ⟨51⟩ ESMFold2-Min Loss Support 
The schema supports deriving ESMFold2-style flat atom-list tensors in a collator: diffusion MSE, smooth LDDT, distogram, resolved/pLDDT, PAE, and PDE confidence losses can all be computed from resolved atom coordinates and masks. Default loss metadata recorded for this build:
  * protein atom weight: `1x`
  * smooth LDDT cutoff: `15 A`
  * distogram bins: `64`, range `2-22 A`


##   ⟨52⟩ References 
  * ESMFold2 preprint: <https://www.biorxiv.org/content/10.64898/2026.06.03.729735v1>
  * Biohub ESM repository: <https://github.com/Biohub/esm>
  * ESMFold2 model page: <https://huggingface.co/biohub/ESMFold2>


##   ⟨53⟩ Split Policy 
Rows are split by connected components over exact sequence duplicate groups, 30% MMseqs2 sequence clusters, Foldseek structure clusters, PDB ID, and biological assembly membership. The builder fails before upload if any leakage assertion fails.

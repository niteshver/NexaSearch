# pandas.api.extensions.ExtensionArray.shape#

- property ExtensionArray.shape[source]#
- Return a tuple of the array dimensions. For ExtensionArrays, this is always a 1-tuple containing the length of the array, since ExtensionArrays are 1-dimensional. See also 
  - `numpy.ndarray.shape`
  - Similar attribute which returns the shape of an array.
  - `DataFrame.shape`
  - Return a tuple representing the dimensionality of the DataFrame.
  - `Series.shape`
  - Return a tuple representing the dimensionality of the Series.
 Examples >>> arr = pd.array([1, 2, 3]) >>> arr.shape (3,)

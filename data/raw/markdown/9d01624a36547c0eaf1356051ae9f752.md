# pandas.BooleanDtype#

- class pandas.BooleanDtype[source]#
- Extension dtype for boolean data. This is a pandas Extension dtype for boolean data with support for missing values. BooleanDtype is the dtype companion to `BooleanArray` ,
which implements Kleene logic (sometimes called three-value logic) for
logical operations. See Kleene logical operations for more.Warning BooleanDtype is considered experimental. The implementation and parts of the API may change without warning. Attributes **None**Methods **None**See also

#   ⟨47⟩ The False Prosperity of AI-Generated Text Detection: A Cross-Benchmark Evaluation 
> **Anonymous ACL Submission**
This repository contains the manuscript for _"The False Prosperity of AI-Generated Text Detection: A Cross-Benchmark Evaluation."_ The paper challenges the prevailing narrative that AI-text detection is a solved problem, arguing that reported high performance reflects **benchmark-level overfitting** rather than robust detection capability.
* * *
##   ⟨38⟩ Overview 
Supervised AI-text detectors routinely report F1 scores above 0.95 on individual benchmarks, and zero-shot detectors are described as inherently robust. We hypothesize that these results arise not from learning the true human-vs-machine distinction, but from exploiting **benchmark-specific pipeline artifacts** ”consistent data sources, prompt templates, decoding parameters, and post-processing that are shared within each benchmark.
We substantiate this claim through a **Cross-Benchmark Evaluation Framework** :  
| Dimension  | Scale  |  
| --- | --- |  
| Benchmarks  | 11 (DetectRL, M4, RAID, CHEAT, HC3, Ghostbuster, TuringBench, DetectRL-X, CUDRT, MAGE, StumblingBlocks)  |  
| Supervised detectors  | 8 (RoBERTa, DeBERTa, BiScope, Qwen3, DetectAnyLLM)  |  
| Zero-shot detectors  | 8 (DetectGPT, Fast-DetectGPT, Binoculars, DNA-GPT, GECScore, etc.)  |  
| Evaluation matrix  | 10 × 10 × 16  |  
###   ⟨39⟩ Key Findings 
  1. **Benchmark-level overfitting** ”Supervised detectors suffer substantial cross-benchmark F1 degradation due to coupling with benchmark construction pipelines.
  2. **Threshold calibration dependence** ”Zero-shot robustness is largely attributable to per-benchmark threshold tuning; applying a fixed threshold across benchmarks collapses performance.
  3. **Pipeline similarity matters** ”Cross-benchmark performance is strongly predicted by the similarity of benchmark construction pipelines.
  4. **Nonlinear interaction of shifts** ”Prompt, domain, and model shifts compound beyond additive effects in cross-benchmark settings.

# pandas.tseries.offsets.FY5253Quarter.variation#

- FY5253Quarter.variation#
- Return the variation of the fiscal year. The variation determines how the fiscal year end is calculated. It can be either “nearest” or “last”. 
  - Returns:
    - str
    - Either “nearest” or “last”.
 See also 
  - `FY5253.weekday`
  - Return the weekday used by the fiscal year.
  - `FY5253.startingMonth`
  - Return the starting month of the fiscal year.
 Examples >>> offset = pd.offsets.FY5253(weekday=4, startingMonth=12, variation="nearest") >>> offset.variation 'nearest'

# pandas.Series.str.isdecimal#

- Series.str.isdecimal()[source]#
- Check whether all characters in each string are decimal. This is equivalent to running the Python string method `str.isdecimal()` for each element of the Series/Index. If a string
has zero characters,`False` is returned for that check.
  - Returns:
    - Series or Index of bool
    - Series or Index of boolean values with the same length as the original Series/Index.

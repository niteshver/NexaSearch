# pandas.CategoricalIndex.append#

- 
CategoricalIndex.append(*other* )[source]#
- Append a collection of Index options together. This method concatenates one or more Index objects to the current index, returning a new Index containing all elements in order. 
  - Parameters:
    - **other** Index or list/tuple of indices
    - Single Index or a collection of indices, which can be either a list or a tuple.
  - Returns:
    - Index
    - Returns a new Index object resulting from appending the provided other indices to the original Index.
 See also 
  - `Index.insert`
  - Make new Index inserting new item at location.

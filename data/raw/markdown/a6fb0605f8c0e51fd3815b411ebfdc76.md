##   ⟨57⟩ Przetwarzanie 
  1. Pobranie metadanych i pełnych tekstów przez API SAOS (`dump/judgments`).
  2. Ekstrakcja pól: dane sądowe, skład, treść, streszczenie, rozstrzygnięcie, przywołane przepisy.
  3. Usunięcie tagów HTML z `textContent`.
  4. Deduplikacja po `id` i hashu tekstu.
  5. Redakcja PII (numery telefonów → `[PHONE]`, emaile → `[EMAIL]`, numery PESEL → `[PESEL]`).
  6. Normalizacja tekstu (whitespace).
  7. Dekontaminacja (n-gram overlap z lokalnym korpusem referencyjnym: LLMzSzŁ, PoQuAD, PES).
  8. Wygenerowanie audytu jakości i próbki do ręcznego przeglądu.


##   ⟨58⟩ Audyt jakości 
  * **PII (przed redakcją):** 2,064 telefony, 621 emaile, 175 PESEL → zredagowane
  * **Duplikaty:** 1,608 usuniętych
  * **Dekontaminacja:** 113 rekordów z n-gram overlap
  * **Werdykt:** Obiecujący, gotowy do dalszej ewaluacji


##   ⟨59⟩ Licencja 
Orzeczenia sądowe są dokumentami urzędowymi i jako takie stanowią dobro publiczne. Projekt używa wyłącznie publicznie dostępnych danych z API SAOS.

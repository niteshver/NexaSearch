# pandas.NA#

- pandas.NA = <NA>#
- NA (“not available”) missing value indicator. Warning Experimental: the behaviour of NA can still change without warning. The NA singleton is a missing value indicator defined by pandas. It is used in certain new extension dtypes (currently the “string” dtype). See also 
  - `numpy.nan`
  - Floating point representation of Not a Number (NaN) for numerical data.
  - `isna`
  - Detect missing values for an array-like object.
  - `notna`
  - Detect non-missing values for an array-like object.
  - `DataFrame.fillna`
  - Fill missing values in a DataFrame.
  - `Series.fillna`
  - Fill missing values in a Series.

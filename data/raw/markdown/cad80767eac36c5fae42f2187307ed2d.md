# pandas.Timestamp.tzname#

- Timestamp.tzname()#
- Return time zone name. This method returns the name of the Timestamp’s time zone as a string. See also 
  - `Timestamp.tzinfo`
  - Returns the timezone information of the Timestamp.
  - `Timestamp.tz_convert`
  - Convert timezone-aware Timestamp to another time zone.
 Examples >>> ts = pd.Timestamp('2023-01-01 10:00:00', tz='Europe/Brussels') >>> ts Timestamp('2023-01-01 10:00:00+0100', tz='Europe/Brussels') >>> ts.tzname() 'CET'

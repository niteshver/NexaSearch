# arXivTrackbacks
Trackbacks indicate external web sites that link to articles in arXiv.org. Trackbacks do not reflect the opinion of arXiv.org and may not reflect the opinions of that article's authors.
## Trackback guide
By sending a trackback, you can notify arXiv.org that you have created a web page that references a paper. Popular blogging software supports trackback: you can send us a trackback about this paper by giving your software the following _trackback URL:_
> https://arxiv.org/trackback/{arXiv_id}
Some blogging software supports _trackback autodiscovery_ -- in this case, your software will automatically send a trackback as soon as your create a link to our abstract page. See our trackback help page for more information.

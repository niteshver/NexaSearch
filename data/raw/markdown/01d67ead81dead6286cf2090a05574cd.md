# pandas.api.typing.DataFrameGroupBy.diff#

- 
DataFrameGroupBy.diff(*periods=1* )[source]#
- First discrete difference of element. Calculates the difference of each element compared with another element in the group (default is element in previous row). 
  - Parameters:
    - **periods** int, default 1
    - Periods to shift for calculating difference, accepts negative values.
  - Returns:
    - Series or DataFrame
    - First differences.
 See also 
  - `Series.diff`
  - Apply function diff to a Series.
  - `DataFrame.diff`
  - Apply function diff to each row or column of a DataFrame.

# pandas.Period.daysinmonth#

- Period.daysinmonth#
- Get the total number of days of the month that this period falls on. Deprecated since version 3.1.0: Use `Period.days_in_month` instead.
  - Returns:
    - int
 See also 
  - `Period.days_in_month`
  - Return the days of the month.
  - `Period.day_of_year`
  - Return the day of the year.
 Examples >>> p = pd.Period("2018-03-11", freq='h') >>> p.days_in_month 31

#   ⟨35⟩ HDF5 Virtual Dataset External File Read ModelScan Bypass 
This PoC shows that an HDF5 model file can contain a Virtual Dataset (VDS) mapping to a dataset in another HDF5 file.
When the dataset in the main `.h5` file is read, HDF5 follows the VDS mapping and reads data from the external HDF5 source file. ModelScan 0.8.8 reports zero issues and skips the file as `MODEL_CONFIG not found`.
##   ⟨36⟩ Files 
  * `hdf5_vds_file_read.h5` - main PoC HDF5 file containing the virtual dataset.
  * `vds_source_secret.h5` - external HDF5 file read through the VDS mapping.
  * `build_and_verify.py` - builds the PoC and verifies the behavior.
  * `verify_report.json` - local verification output.


##   ⟨37⟩ Reproduction 
Run:

```
python build_and_verify.py

```

Expected results:
  * `verification.is_virtual=true`
  * `verification.read_marker_ok=true`
  * `modelscan.parsed.summary.total_issues=0`
  * `modelscan.parsed.summary.skipped.total_skipped=1`


The marker read through the main HDF5 file is:

```
HDF5_VDS_FILE_READ_MARKER!!

```

# pandas.api.typing.Resampler.count#

- final Resampler.count()[source]#
- Compute count of group, excluding missing values. This method returns the number of non-null values in each resampled time period. 
  - Returns:
    - Series or DataFrame
    - Count of values within each group.
 See also 
  - `Series.groupby`
  - Apply a function groupby to a Series.
  - `DataFrame.groupby`
  - Apply a function groupby to each row or column of a DataFrame.

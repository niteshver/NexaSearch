# pandas.api.typing.Resampler.size#

- final Resampler.size()[source]#
- Compute group sizes. This method returns the number of rows in each resampled time period, including rows with missing values. 
  - Returns:
    - Series
    - Number of rows in each group.
 See also 
  - `Series.groupby`
  - Apply a function groupby to a Series.
  - `DataFrame.groupby`
  - Apply a function groupby to each row or column of a DataFrame.

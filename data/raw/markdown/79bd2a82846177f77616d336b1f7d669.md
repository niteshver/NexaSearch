#   ⟨43⟩ AdithyaSK/data_agent_rl_environment_train_multireward 
Multi-reward variant of `AdithyaSK/data_agent_rl_environment_train`⟨44⟩ (2238 tasks, identical data/instructions). The **only** change: each task's verifier now emits a **`reward.json`**with three named rewards instead of a single float:  
| reward  | meaning  | range  |  
| --- | --- | --- |  
| `correctness`  | graded answer matches gold (exact / numeric / LLM-judge)  | 0 or 1  |  
| `submission`  | a non-empty answer was written to `/workdir/answer.txt`  | 0 or 1  |  
| `tool_efficiency`  | fewer agent tool calls -> higher; `clip(1 - n_calls/TOOL_BUDGET, 0, 1)`  | 0..1 or null  |  
  * If nothing is submitted, all three are `0`.
  * `tool_efficiency` is a **raw** signal (not gated on correctness) — the RL reward combiner decides gating/weights. It's `null` if the harness didn't report a tool-call count.
  * Tool-call count is read from `/workdir/.n_tool_calls` (written by the harness) or the `N_TOOL_CALLS` env var. `TOOL_BUDGET` defaults to 15.


Harbor natively carries named rewards (`VerifierResult.rewards: dict[str,float]`), reading `/logs/verifier/reward.json`.
Built for GRPO RL on the data-agent bash environment (see the parent dataset for provenance).

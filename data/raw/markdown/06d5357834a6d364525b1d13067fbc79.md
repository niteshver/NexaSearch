#   ⟨45⟩ AM11 DED 316L Texture and Hardness 
This dataset contains 45 tabular QA/SFT records derived from DED 316L thin-wall experiments.
##   ⟨42⟩ Tasks 
  * 25 records: process parameters and wall height -> average Vickers hardness HV.
  * 7 records: cooling rate -> texture anisotropy Ahkl and average Vickers hardness HV.
  * 13 records: cooling rate -> average Vickers hardness HV only, because Ahkl is missing in the source CSV.


Rows with missing Ahkl do not ask for texture anisotropy and do not contain null targets in `annot`.
##   ⟨43⟩ Schema 
Each row uses the unified Forge schema:
  * `query`: task template plus the structured input values.
  * `annot`: JSON string target.
  * `reasoning`: null.
  * `cate`: task category.
  * `task`: Forge task ID.
  * `metadata`: JSON string with source, units, task subtype, and target availability.
  * `image`: null, because this is a tabular dataset.


##   ⟨44⟩ Source Notes 
The source files are `Fig3.csv` and `Fig10.csv` from the local DED 316L texture/hardness dataset. The scan-speed unit is ambiguous in the source and is preserved with a metadata note.

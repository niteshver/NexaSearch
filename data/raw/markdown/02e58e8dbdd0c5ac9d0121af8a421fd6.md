#   ⟨43⟩ CR1 empty-string text embedding for DreamDojo distillation 
The empty-string text embedding used by every distillation stage of the DreamDojo⟨44⟩ pipeline (warmup + self-forcing).
Redistributes a single ~103 MB file originally at:

```
nvidia/Cosmos-Predict2.5-2B → robot/action-cond/cr1_empty_string_text_embeddings.pt

```

That upstream repo is gated and the license workflow is flaky for some users. This mirror avoids the gate for anyone reproducing our warmup / self-forcing runs on the `Cocoyawn32/dreamdojo-piper-warmup-4step` dataset.

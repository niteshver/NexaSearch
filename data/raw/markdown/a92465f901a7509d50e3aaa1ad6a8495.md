|  1. OVERVIEW  |  
|  ------------------------------------------------------------  |  
|   |  
|  User Experience (UX) is the discipline of designing products, services, and systems that enable users to achieve their goals efficiently, effectively, and with satisfaction.  |  
|   |  
|  UX is not only about visual design.  |  
|   |  
|  It encompasses:  |  
|   |  
|  - Understanding users  |  
|  - Solving real problems  |  
|  - Designing interactions  |  
|  - Improving usability  |  
|  - Supporting business objectives  |  
|  - Measuring outcomes  |  
|  - Continuously improving experiences  |  
|   |  
|  A successful UX balances:  |  
|   |  
|  • User Needs  |  
|  • Business Goals  |  
|  • Technical Feasibility  |  
|   |  
|  Good UX minimizes friction while maximizing value.  |  
|   |  
|  ------------------------------------------------------------  |  
|  2. WHAT IS USER EXPERIENCE?  |  
|  ------------------------------------------------------------  |  
|   |  
|  ISO 9241-210 defines User Experience as:  |  
|   |  
|  "A person's perceptions and responses resulting from the use and anticipated use of a product, system, or service."  |  
|   |  
|  UX includes:  |  
|   |  
|  - Emotions  |  
|  - Expectations  |  
|  - Perceptions  |  
|  - Behaviors  |  
|  - Accessibility  |  
|  - Learnability  |  
|  - Efficiency  |  
|  - Satisfaction  |  
|   |  
|  ------------------------------------------------------------  |  
|  3. UX VS UI  |  
|  ------------------------------------------------------------  |  
|   |  
|  UX Design  |  
|   |  
|  Focuses on:  |  
|   |  
|  - Problem solving  |  
|  - User goals  |  
|  - Research  |  
|  - Structure  |  
|  - Navigation  |  
|  - Information architecture  |  
|  - User flows  |  
|  - Testing  |  
|   |  
|  UI Design  |  
|   |  
|  Focuses on:  |  
|   |  
|  - Visual appearance  |  
|  - Typography  |  
|  - Colors  |  
|  - Components  |  
|  - Layout  |  
|  - Icons  |  
|  - Visual hierarchy  |  
|  - Brand consistency  |  
|   |  
|  UX answers:  |  
|   |  
|  "Does it work well?"  |  
|   |  
|  UI answers:  |  
|   |  
|  "Does it look and feel good?"  |

#   ⟨51⟩ COCO-Camera 
![camera map collage](https://huggingface.co/datasets/KangLiao/COCO-Camera/resolve/main/analysis/COCO-Camera.png)⟨52⟩
Per-image camera parameter annotations for the **COCO** dataset (`detection-datasets/coco`; train + val, ~122K images across 42 shards), captioned by the **Puffin-World**⟨53⟩ model. More captioned datasets are provided in our **Puffin-16M**⟨54⟩ website.
The collage above visualizes the camera maps on sample images — each pair shows the **up field** (green arrows: the projected gravity-up direction) and the **latitude field** (colored contours: angle above/below the horizon).
##   ⟨46⟩ Format 
One `.tar` per source shard (`coco_train_00000.tar` … `coco_train_00039.tar`, `coco_val_00000.tar`, `coco_val_00001.tar`), each containing one `.json` per image named by the COCO 12-digit image id (e.g. `000000000139.json`).
Each JSON holds the predicted monocular camera parameters:  
| Field  | Meaning  | Unit  |  
| --- | --- | --- |  
| `roll`  | camera roll  | radians  |  
| `pitch`  | camera pitch  | radians  |  
| `vfov`  | vertical field-of-view  | radians  |  
| `k1`  | radial distortion coefficient  | –  |  
| `parse_ok`  | whether the model output parsed within valid ranges  | bool  |  
Example:

```
{"roll": -0.0104, "pitch": 0.0268, "vfov": 0.9044, "k1": 0.0000, "parse_ok": true}

```

##   ⟨47⟩ Camera Parameter Distributions 
Histograms of the predicted roll / pitch / vertical-FoV over the whole dataset (train + val; proportion of valid samples per 10° bin; `parse_ok=False` excluded).
![coco camera stats](https://huggingface.co/datasets/KangLiao/COCO-Camera/resolve/main/analysis/coco_camera_stats.png)⟨55⟩  
| split  | roll μ / med / σ  | pitch μ / med / σ  | FoV μ / med / σ  |  
| --- | --- | --- | --- |  
| all (122K)  | 0.0° / 0.0° / 6.2°  | −7.3° / −4.0° / 15.0°  | 34.9° / 32.5° / 11.7°  |  
  * **Roll** is sharply peaked at 0° (photos shot level).
  * **Pitch** is clearly negative (median ≈ −4°) — COCO scenes are often shot looking somewhat downward at objects/people.
  * **FoV** centers around 20–45° (median ≈ 32°) with a long wide-angle tail.


If you'd like a dataset with a more diverse and uniform distribution of camera parameters, please refer to our Puffin-4M⟨56⟩ and Puffin-16M⟨57⟩ datasets.

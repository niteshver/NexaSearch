# pandas.Timestamp.to_julian_date#

- Timestamp.to_julian_date()#
- Convert Timestamp to a Julian Date. This method returns the number of days as a float since 0 Julian date, which is noon January 1, 4713 BC. See also 
  - `Timestamp.toordinal`
  - Return proleptic Gregorian ordinal.
  - `Timestamp.timestamp`
  - Return POSIX timestamp as float.
  - `Timestamp`
  - Represents a single timestamp.
 Examples >>> ts = pd.Timestamp('2020-03-14T15:32:52') >>> ts.to_julian_date() 2458923.147824074

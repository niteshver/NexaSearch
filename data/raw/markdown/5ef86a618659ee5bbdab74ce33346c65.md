# pandas.tseries.offsets.BYearEnd.is_month_end#

- 
BYearEnd.is_month_end(*ts* )#
- Return boolean whether a timestamp occurs on the month end. This method checks if the given timestamp falls on the last day of a month, taking into account the frequency’s normalization settings. 
  - Parameters:
    - **ts** Timestamp
    - The timestamp to check.
 See also 
  - `is_month_start`
  - Return boolean whether a timestamp occurs on the month start.
 Examples >>> ts = pd.Timestamp(2022, 1, 1) >>> freq = pd.offsets.Hour(5) >>> freq.is_month_end(ts) False

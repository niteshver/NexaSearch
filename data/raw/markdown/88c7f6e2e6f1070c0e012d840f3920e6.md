# pandas.Timestamp.strptime#

- 
classmethod Timestamp.strptime(*date_string* ,*format* )#
- Convert string argument to datetime. This method is not implemented; calling it will raise NotImplementedError. Use pd.to_datetime() instead. 
  - Parameters:
    - **date_string** str
    - String to convert to a datetime.
    - **format** str, default None

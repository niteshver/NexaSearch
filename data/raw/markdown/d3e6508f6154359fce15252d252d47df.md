# Title:Singular components of the Springer fiber in the two-columns case

View PDF HTML (experimental)
            Abstract:  We give an equational description of the components of the Springer fiber in the two-columns case. We deduce a necessary and sufficient criterion of singularity for the components of two-columns type: a component is singular if and only if it contains too many elements, among a finite set of flags of a certain kind.

# pandas.api.types.is_signed_integer_dtype#

- 
pandas.api.types.is_signed_integer_dtype(*arr_or_dtype* )[source]#
- Check whether the provided array or dtype is of a signed integer dtype. Unlike in is_any_int_dtype, timedelta64 instances will return False. The nullable Integer dtypes (e.g. pandas.Int64Dtype) are also considered as integer by this function. 
  - Parameters:
    - **arr_or_dtype** array-like or dtype
    - The array or dtype to check.
  - Returns:
    - boolean
    - Whether or not the array or dtype is of a signed integer dtype and not an instance of timedelta64.
 See also 
  - `api.types.is_integer_dtype`
  - Check whether the provided array or dtype is of an integer dtype.
  - `api.types.is_numeric_dtype`
  - Check whether the provided array or dtype is of a numeric dtype.
  - `api.types.is_unsigned_integer_dtype`
  - Check whether the provided array or dtype is of an unsigned integer dtype.

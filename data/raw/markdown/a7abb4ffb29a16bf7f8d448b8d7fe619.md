# Title:Secure quantum direct communication with continuous variables

View PDF HTML (experimental)
            Abstract:  We present a protocol that allows Alice and Bob to safely communicate by using continuous variable systems and without sharing any secret key. This is possible by a suitable encoding of the plain message into a phase-space lattice of bosonic modes.

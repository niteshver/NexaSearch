#   ⟨61⟩ Animetix Otaku Expert Fine-Tuning Dataset 
This is the unified expert Supervised Fine-Tuning (SFT) training dataset for the **Animetix Otaku Reasoning** models. It is written 100% in French without code-switching.
##   ⟨55⟩ Dataset Proportions 
To ensure a balanced and robust reasoning model, the dataset is built using strict mathematical proportions:
  * **80% Specialized Otaku Knowledge:** Data-driven relational facts about anime, manga, seiyuu, French voice actors (VF), magazines, awards, anisongs, and volume/episode structures.
  * **5% Meta Otaku Vocabulary:** Explanations of otaku terminology, conventions, and culture.
  * **15% General & Multi-turn Dialogue:** Conversational capabilities, ChatML formatted dialogues, and multi-turn interactions.


##   ⟨56⟩ Content & Generator Modules 
The dataset compiles examples generated across several domains:
  1. **Songs & Seiyuu:** Relational facts connecting anime theme songs, singers, and original Japanese voice actors.
  2. **French Market Relations:** Details on French voice actors (VF), editors, diffuseurs, and publishers.
  3. **Transmedia & Serialization:** Connections between anime adaptations, original manga, authors, and serialization magazines (e.g., Shonen Jump).
  4. **Synthetic refuse & RAG:** Negative refusal samples (anti-hallucination guardrails) and instructions for using MCP tools and RAG contexts.


##   ⟨57⟩ Research References 
The training dataset creation and pipeline design are based on the following research papers:
###   ⟨58⟩ 1. Reasoning & Cognitive Architectures 
  * **DeepSeek-R1:** DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning⟨62⟩ (DeepSeek-AI, 2025). Inspired the Thinking Mode internal trace.
  * **STaR:** STaR: Bootstrapping Reasoning With Reasoning⟨63⟩ (Zelikman et al., NeurIPS 2022). Core of reasoning trajectory generation.
  * **Chain-of-Verification (CoVe):** Chain-of-Verification Reduces Hallucination in Large Language Models⟨64⟩ (Dhuliawala et al., 2023). Relied on for factual alignment.
  * **Tree of Thoughts (ToT):** Tree of Thoughts: Deliberate Problem Solving with Large Language Models⟨65⟩ (Yao et al., 2023). Used in Akinetix search trees.
  * **MemGPT:** MemGPT: Towards LLMs as Operating Systems⟨66⟩ (Packer et al., 2023). Underpins episodic memory compression.
  * **ReSearch:** ReSearch: Learning to Reason with Search for LLMs via Reinforcement Learning⟨67⟩ (2025). Integrates inline tool search within thinking traces.


###   ⟨59⟩ 2. Agentic Protocols & Tool Usage 
  * **ReAct:** ReAct: Synergizing Reasoning and Acting in Language Models⟨68⟩ (Yao et al., ICLR 2023). Orchestrates the dynamic tool agent loop.
  * **Toolformer:** Toolformer: Language Models Can Teach Themselves to Use Tools⟨69⟩ (Schick et al., 2023). Guides autonomous API calling triggers.
  * **Mixture-of-Agents (MoA):** Mixture-of-Agents Enhances Large Language Model Capabilities⟨70⟩ (Wang et al., 2024). Governs consensus voting across specialized agents.


###   ⟨60⟩ 3. Efficient Fine-Tuning & Inference 
  * **QLoRA:** QLoRA: Efficient Finetuning of Quantized LLMs⟨71⟩ (Dettmers et al., NeurIPS 2023).
  * **LoRA:** LoRA: Low-Rank Adaptation of Large Language Models⟨72⟩ (Hu et al., ICLR 2022).
  * **S-LoRA:** S-LoRA: Serving Thousands of Concurrent LoRA Adapters⟨73⟩ (Sheng et al., 2023). Enables concurrently serving multiple character personality adapters.
  * **Qwen3.5 Base Architecture:** Qwen3.5 Technical Report⟨74⟩ (Qwen Team, 2024).

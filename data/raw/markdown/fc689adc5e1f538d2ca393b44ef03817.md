# pandas.tseries.offsets.Hour.name#

- Hour.name#
- Return a string representing the base frequency. Deprecated since version 3.1.0: The `.name` property is deprecated. Use`.rule_code` instead.This is typically a short string alias (e.g., ‘h’ for hourly, ‘D’ for daily) used to identify the offset type, regardless of the n multiplier. See also 
  - `tseries.offsets.Week`
  - Represents a weekly offset.
  - `DateOffset`
  - Base class for all other offset classes.
  - `tseries.offsets.Day`
  - Represents a single day offset.
  - `tseries.offsets.MonthEnd`
  - Represents a monthly offset that snaps to the end of the month.
 Examples >>> pd.offsets.Hour().name 'h' >>> pd.offsets.Hour(5).name 'h'

##   ⟨58⟩ What this dataset does NOT claim 
Like every dataset in this collection, this teaches a model to narrate a correctly-computed Horary Astrology (Prashna) reading using its own traditional rules faithfully and with citations. It does not, and cannot, contain any ground truth about whether any prediction comes true — no such data exists for any divination system. See the companion repo's top-level README for the shared "what these datasets don't claim" statement that applies across the whole collection.
##   ⟨59⟩ Known limitations 
  * Responses deliberately do NOT give a yes/no answer — they describe which traditional factors are examined, since no ground truth for question outcomes exists. If your use case wants yes/no-style outputs, that requires a design decision this dataset does not make for you.
  * Query-moment timestamps here are synthetic (randomly sampled 2015-2026) rather than real query moments, since no real querent data was used.
  * No specialized horary techniques beyond the shared yoga/dignity rule set (e.g. no Moon void-of-course detection, no applying/separating aspect analysis).

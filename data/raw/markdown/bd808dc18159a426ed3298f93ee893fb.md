# pandas.Timestamp.isoweekday#

- Timestamp.isoweekday()#
- Return the day of the week represented by the date. Monday == 1 … Sunday == 7. See also 
  - `Timestamp.weekday`
  - Return the day of the week with Monday=0, Sunday=6.
  - `Timestamp.isocalendar`
  - Return a tuple containing ISO year, week number and weekday.
  - `datetime.date.isoweekday`
  - Equivalent method in datetime module.
 Examples >>> ts = pd.Timestamp('2023-01-01 10:00:00') >>> ts Timestamp('2023-01-01 10:00:00') >>> ts.isoweekday() 7

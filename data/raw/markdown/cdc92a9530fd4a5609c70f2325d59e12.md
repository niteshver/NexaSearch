    # Title:Moufang symmetry V. Triple closure

View PDF HTML (experimental)
            Abstract:  Triple closure of the infinitesimal translations of an analytic Moufang loop is inquired. This property is equivalent to reductivity and relates Mal'tsev algebras to the Lie triple systems.

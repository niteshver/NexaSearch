# pandas.Series.notna#

- Series.notna()[source]#
- Detect existing (non-missing) values. Return a boolean same-sized Series indicating if the values are not NA. Non-missing values get mapped to True. Characters such as empty strings `''` or`numpy.inf` are not considered NA values.
NA values, such as None or`numpy.NaN` , get mapped to False
values.
  - Returns:
    - Series
    - Mask of bool values for each element in Series that indicates whether an element is not an NA value.

#   ⟨50⟩ PowerAtlas CO2 Snapshot v2 
This is a discoverability mirror of the canonical Zenodo release:
**Aheiev, D. (2026)._PowerAtlas CO2 Snapshot v2: current web-atlas asset-level measured and modelled power-plant emissions subset_ [Data set]. Inzonex. Zenodo. <https://doi.org/10.5281/zenodo.21206469>**
Please cite the Zenodo DOI, not this mirror page. The concept DOI for the latest PowerAtlas CO2 snapshot is <https://doi.org/10.5281/zenodo.20723333>.
##   ⟨45⟩ What is included 
Frozen 2026-07-05 snapshot of the current PowerAtlas asset-level CO2 subset:  
| Metric  | Value  |  
| --- | --- |  
| Power-plant records  | 4,155  |  
| Regulator-measured records  | 1,157  |  
| Climate TRACE modelled records  | 2,998  |  
| Countries  | 42  |  
| Total asset-level CO2  | approx. 7.516 Gt CO2/year  |  
| License  | CC BY 4.0  |  
Rows are included only when PowerAtlas classifies the asset-level CO2 value as `measured` or `modelled`. Calculated fuel-factor estimates and unavailable/not-applicable rows are excluded from this CO2 snapshot.
##   ⟨46⟩ Files 
  * `poweratlas_co2_snapshot_v2_2026-07-05.csv` - main UTF-8 CSV dataset.
  * `poweratlas_co2_snapshot_v2_2026-07-05.json` - same records as JSON.
  * `data_dictionary.csv` - field definitions.
  * `counts.json` - exact release counts and generation metadata.
  * `CITATION.cff` - citation metadata.
  * `LICENSE` - CC BY 4.0.
  * `SHA256SUMS.txt` - checksums from the Zenodo release package.


##   ⟨47⟩ Provenance 
The snapshot is derived from the PowerAtlas web-atlas build and combines asset-level plant data and emissions provenance from open sources including WRI Global Power Plant Database, Global Energy Monitor, Climate TRACE, US EPA GHGRP, EU ETS/EUTL, WorldClim/Koppen-Geiger and Ember/OWID, each under its respective reuse terms.
##   ⟨48⟩ Important limitations 
  * This is not the full PowerAtlas plant universe. It is the CO2 subset: records with measured or modelled asset-level CO2 values.
  * `co2_source` must be used before interpreting values. Regulator-measured and modelled records are intentionally separated.
  * Climate TRACE records are modelled estimates, not direct regulator measurements.
  * The v2 snapshot differs from the archived v1.0 release. v2 is aligned with the current web-atlas generator after deduplication, placeholder filtering and provenance fixes.

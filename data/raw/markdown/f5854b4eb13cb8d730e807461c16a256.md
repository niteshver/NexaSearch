#   ⟨46⟩ FL-OMR-Dataset 
Official dataset and pretrained models for the project:
**Federated OMR for Automated Examination Paper Digitization and Assessment**
This repository provides the datasets, pretrained models, template files, and detection model used in our experiments on Federated Learning for Optical Mark Recognition (OMR).

#   ⟨48⟩ Dataset Description 
The repository contains three datasets used in the experiments.  
| Dataset  | Description  |  
| --- | --- |  
| **dataset1**  | Original OMR dataset adapted from the work of Afifi et al.  |  
| **dataset2**  | Additional dataset collected under different acquisition conditions.  |  
| **dataset3**  | Additional dataset with different answer sheet layouts and writing styles.  |  
Each dataset contains:
  * **roi/**  
Cropped answer regions used for EfficientNet-B0 classification.
  * **sheets/**  
Original examination sheets used for end-to-end evaluation.


* * *
#   ⟨49⟩ Model Answer Templates 
The **modelAnswer/** directory contains:
  * examination templates,
  * answer keys,
  * metadata required for ROI extraction and automatic grading.


These files are necessary to reproduce the complete OMR pipeline.

#   ⟨50⟩ Pretrained Models 
The **weights/** directory contains all trained EfficientNet-B0 checkpoints.
###   ⟨42⟩ warm_start/

###   ⟨45⟩ centralized/

#   ⟨52⟩ Experimental Pipeline 
The complete OMR pipeline consists of the following stages:
  1. Detect answer bubbles using YOLO.
  2. Align examination sheets with the template.
  3. Crop answer regions (ROI).
  4. Classify each ROI using EfficientNet-B0.
  5. Generate the final grading results.

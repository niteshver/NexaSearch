#   ⟨57⟩ TFT Set17 Unit Detector YOLO 
YOLO-format unit detector dataset for TFT Set 17 experiments.
This package combines:
  * synthetic board screenshots made from arena textures and modelviewer unit renders
  * clean multi-angle modelviewer unit reference images


The dataset is intended for training a single-class `unit` object detector.

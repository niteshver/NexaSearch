# pandas.Timedelta.value#

- Timedelta.value#
- Return the value of Timedelta object in nanoseconds. Return the total seconds, milliseconds and microseconds of the timedelta as nanoseconds. 
  - Returns:
    - int
 See also 
  - `Timedelta.unit`
  - Return the unit of Timedelta object.
 Examples >>> pd.Timedelta(1, "us").value 1000

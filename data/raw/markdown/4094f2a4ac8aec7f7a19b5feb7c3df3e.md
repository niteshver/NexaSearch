##   ⟨55⟩ Computation 
Deterministic (pyswisseph solar longitude for Year/Month pillar boundaries via the 'Jie' solar terms; continuous day-count cycle for Day/Hour pillars) — the solar-calendar variant of BaZi used by most professional software, not lunar-phase-based.
##   ⟨56⟩ Validation status — read before trusting this at scale 
Year-pillar output cross-checked against 5 independently-verifiable, widely-known real-world Chinese zodiac year designations (1984 Wood Rat, 2000 Metal Dragon, 2020 Metal Rat, 1990 Metal Horse, 2024 Wood Dragon) — all 5 matched exactly. Month/Day/Hour pillar precision (in particular the 1900-01-31 Jia-Zi day-cycle anchor) was NOT independently verified against a live reference calculator in the build environment (no internet access to a BaZi tool at build time) — internal consistency (60-day periodicity, correct 10/12 stem/branch cycling) was checked, but this is not the same as correctness. Spot-check a sample of Day/Hour pillars against an established BaZi calculator before treating this dataset as ground truth.

##   ⟨59⟩ What this dataset does NOT claim 
Like every dataset in this collection, this teaches a model to narrate a correctly-computed Chinese BaZi (Four Pillars of Destiny) reading using its own traditional rules faithfully and with citations. It does not, and cannot, contain any ground truth about whether any prediction comes true — no such data exists for any divination system. See the companion repo's top-level README for the shared "what these datasets don't claim" statement that applies across the whole collection.
##   ⟨60⟩ Known limitations 
  * No Luck Pillars (Da Yun) — these require gender + a forward/backward-counting rule this version does not implement.
  * No clash/combination detection between pillars (only element-count balance rules).
  * Element-balance rules (4 rule types) are a starting set, not the full body of BaZi pattern analysis (which includes many named 'Ge Ju' structures not covered here).

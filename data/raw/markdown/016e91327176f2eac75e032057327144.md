# pandas.errors.CategoricalConversionWarning#

- exception pandas.errors.CategoricalConversionWarning[source]#
- Warning is raised when reading a partial labeled Stata file using an iterator. This warning helps ensure data integrity and alerts users to potential issues during the incremental reading of Stata files with labeled data, allowing for additional checks and adjustments as necessary. See also 
  - `read_stata`
  - Read a Stata file into a DataFrame.
  - `Categorical`
  - Represents a categorical variable in pandas.
 Examples >>> from pandas.io.stata import StataReader >>> with StataReader("dta_file", chunksize=2) as reader: ... for i, block in enumerate(reader): ... print(i, block) ... # CategoricalConversionWarning: One or more series with value labels...

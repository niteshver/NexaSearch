#   ⟨52⟩ prompt-injection-15k 
A dataset for training prompt injection / jailbreak detection classifiers.
15,000 examples labeled as either a prompt injection attempt (1) or a normal, benign message (0). Includes direct overrides, roleplay jailbreaks, system prompt extraction attempts, obfuscated attacks, multilingual examples, and benign edge cases (imperative tasks, casual use of words like "ignore" or "forget", short or minimal inputs).
##   ⟨48⟩ Fields 
  * `text`: the user message
  * `label`: 0 = clean, 1 = injection


##   ⟨49⟩ Splits 
  * train: 13,500 examples
  * test: 1,500 examples


##   ⟨50⟩ Source 
Synthetically generated using an LLM, then patched with targeted examples to address known classifier failure modes.
##   ⟨51⟩ Usage 

```
from datasets import load_dataset

ds = load_dataset("MistyozAI/prompt-injection-15k")
```

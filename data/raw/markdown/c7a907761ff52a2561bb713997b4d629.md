#   ⟨43⟩ Swecha Telangana ASR Base Model 
##   ⟨44⟩ Model Description 
The **Swecha Telangana ASR Base Model** is a fine-tuned Automatic Speech Recognition (ASR) model built on **OpenAI Whisper Small** for Telugu speech recognition.
This model has been fine-tuned using the **Mozilla Common Voice Scripted Speech 26.0 Telugu** dataset through the Mozilla AI Speech-to-Text Finetuning Blueprint.
##   ⟨45⟩ Base Model 
  * openai/whisper-small


##   ⟨46⟩ Language

#   ⟨64⟩ Fable-5 Traces SFT ChatML 
![Parable⟨65⟩]
**The Claude Fable 5 agent-trace corpus, converted to standard ChatML messages with OpenAI-format tool calls. Load it and train, no format wrangling.**
Glint-Research/Fable-5-traces⟨66⟩ is the largest open corpus of real Claude Fable 5 agent sessions, but it ships as flattened transcript strings that every trainer has to parse themselves. This dataset is that parsing done once, carefully: 4,665 samples restructured into `messages` arrays with typed roles, structured `tool_calls` in OpenAI function-calling format, matched `tool_call_id`s, and `<think>` reasoning preserved on the target turn. It drops straight into any SFT stack that speaks chat templates: axolotl, LLaMA-Factory, TRL, mlx-lm, Unsloth.
This is the exact pipeline used to train the Parable⟨67⟩ model series (Parable-Qwen3-4B-fable⟨68⟩ cut held-out test loss 47% against its base on this data).
##   ⟨55⟩ What a sample looks like 

```
{
  "messages": [
    {"role": "user", "content": "Make a fast paced multiplayer FPS..."},
    {"role": "assistant", "content": "", "tool_calls": [
      {"id": "call_1", "type": "function", "function": {
        "name": "Read",
        "arguments": "{\"file_path\": \"/home/lane/AIArchives/server/index.js\"}"}}]},
    {"role": "tool", "tool_call_id": "call_1", "content": "const express = require..."},
    {"role": "assistant", "content": "<think>\nAlright, I've got a decent overview of the repository...\n</think>", "tool_calls": [
      {"id": "call_2", "type": "function", "function": {
        "name": "Edit",
        "arguments": "{\"file_path\": \"...\", \"old_string\": \"...\", \"new_string\": \"...\"}"}}]}
  ],
  "uid": "f956721a-...#5",
  "session": "f956721a-...",
  "target_type": "tool_use",
  "n_turns": 18,
  "context_truncated": true,
  "tool_args_valid": true
}

```

Each sample is one agent step: the conversation so far, then a final assistant turn carrying the model's `<think>` reasoning plus its action (a tool call or a text reply). The final turn is the training target.

##   ⟨57⟩ Usage 

```
from datasets import load_dataset

ds = load_dataset("AnkitAI/fable-5-traces-sft-chatml", split="train")

# render with any chat template that supports tool calls
from transformers import AutoTokenizer
tok = AutoTokenizer.from_pretrained("Qwen/Qwen3-4B")
text = tok.apply_chat_template(ds[0]["messages"], tokenize=False)

```

For trainers that want single-target masking: mask loss on everything except the final assistant message (`messages[-1]`), which is the step being taught.
##   ⟨58⟩ Data fields 
  * **messages** : ChatML list. Roles `user`, `assistant`, `tool`. Assistant turns may carry `tool_calls` (OpenAI function-calling format, `arguments` as JSON string); tool turns carry the matching `tool_call_id`. The final assistant turn always opens with a `<think>...</think>` block.
  * **uid / session** : provenance keys into the source corpus. 60 sessions produce the 4,665 steps, so neighboring samples share overlapping context. Group by `session` when splitting train/test to avoid leakage.
  * **target_type** : `tool_use` (3,799) or `text` (866), the kind of final turn.
  * **context_truncated** : true when the source's ~7k-character context window cut the start of the conversation (4,121 samples). The sample still parses cleanly; it just begins mid-session.
  * **tool_args_valid** : false when at least one historical tool call's arguments were cut mid-JSON by that same source window (3,102 samples). Target-turn arguments are always valid JSON, only context turns are affected. Filter on this flag if you need every argument string parseable.


##   ⟨59⟩ How it was made 
  1. Parsed each flattened transcript into typed turns (`USER:`, `ASSISTANT (message):`, `ASSISTANT (tool call)`, `TOOL RESULT:` markers).
  2. Normalized tool calls to OpenAI function-calling format with synthesized, correctly paired call IDs.
  3. Dropped leading orphan tool results (results whose call fell off the source's context window) so every sample starts template-clean. Zero orphans remain.
  4. Attached the target: `<think>` reasoning from the source's `cot` field plus the structured action from its `output` field.
  5. Scrubbed for secrets (API keys, tokens, private keys), exact-deduplicated. Nothing was dropped: 4,665 in, 4,665 out.


##   ⟨60⟩ Limitations 
  * Steps from the same session overlap heavily by construction (sliding context window). Deduplicate or split by `session` for evaluation.
  * Two thirds of samples have a truncated context start; models trained on this learn to act mid-session, which matches agent deployment but is not ideal for full-conversation modeling.
  * All traces come from one assistant (Claude Fable 5) doing coding and terminal work. Expect style transfer along with capability.

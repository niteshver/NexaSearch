# pandas.Series.dtypes#

- property Series.dtypes[source]#
- Return the dtype object of the underlying data. Unlike `DataFrame.dtypes` , which returns a Series of dtypes for each
column,`Series.dtypes` returns a single dtype object representing
the type of all elements in the Series.See also 
  - `DataFrame.dtypes`
  - Return the dtypes in the DataFrame.
 Examples >>> s = pd.Series([1, 2, 3]) >>> s.dtypes dtype('int64')

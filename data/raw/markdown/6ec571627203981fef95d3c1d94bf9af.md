    # Title:Two-Loop Heavy-Flavor Contribution to Bhabha Scattering

View PDF HTML (experimental)
            Abstract:  We evaluate the two-loop QED corrections to the Bhabha scattering cross section which involve the vacuum polarization by heavy fermions of arbitrary mass m_f >> m_e. The results are valid for generic values of the Mandelstam invariants s,t,u >> m_e^2.

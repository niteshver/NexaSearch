#   ⟨48⟩ ARC-AGI-3 `tr87` — Agent Trajectories 
Gameplay trajectories from an LLM agent (Claude Code driving a file-relay harness) playing the ARC-AGI-3⟨49⟩ game `tr87`, part of the ARA-as-world-model generalization experiment. The agent builds a structured world model (an Agent-Native Research Artifact) live during play and consults it to crack levels it cannot solve from cold exploration. Companion dataset: arc-agi3-ls20-agent-trajectories⟨50⟩.
Synced continuously during play — every crystallization into the world model pushes here.
##   ⟨45⟩ Layout 

```
reasoning/ara-tr87/    # the agent's world model + reasoning trace (logic/, trace/, staging/)
traces/                 # per-subagent action-reasoning traces: one JSON line per action, with the why
solutions/GAME.md       # status snapshot: progress / mechanic / gotchas / parked reason
solutions/replay/       # per-level winning action scripts (L<n>.txt)
recordings/             # frame-level recordings, one file per session (<game>-<hash>.<agent>.<guid>.recording.jsonl)
episodes/               # turn-level episode logs (concatenated across runs)
logs/                   # harness log + free-form session notes (git history preserves prior sessions)
scorecards/             # ARC API scorecards, when saved
predictions.jsonl       # world-model prediction ledger: consults with confidence + later verdicts
accounting/             # this game's ledger rows (tokens/steps), metrics section, ARA growth curve
demo/                   # ablation / showcase artifacts, when the game has them
sessions_index.json     # one entry per recording session (agent, guid, frames, final state)
manifest.json           # provenance: agent model, repo commit, protocol hash, sync time

```

Repo tags `L<n>-cleared` mark the full record as of each level clear — holdout-ready snapshots for downstream agent-evaluation experiments. Deliberation timing (inter-action gaps), death forensics, and surprise analyses are derivable from the recordings + traces and are not stored separately.
##   ⟨46⟩ Run outcome 
**WON 6/6 levels on 2026-07-06** (`state=WIN`), 7 subagent batons on `claude-opus-4-8`, 963,052 cumulative tokens (input+output only). The game is an escalating legend-substitution cipher; the world model's forward consults were decisive on 5 of 6 levels (see `predictions.jsonl` for the full prediction↔verdict calibration record, C06→C11 in `reasoning/ara-tr87/logic/claims.md` for the mechanic ladder). Full per-baton conversation transcripts are in `transcripts_full/` (the terse per-action why lives in `traces/`).
##   ⟨47⟩ Notes for interpretation (read before analyzing this record) 
  1. **L6 trace`level` labels are distorted by an in-baton respawn.** The L6 baton (`tr87-L6-a1`) first won the game at harness count 485 (15:38); a harness respawn then reset the game to L1, and the baton hand-recleared L1→L5 and re-won at count 336 (15:56). All 402 of its trace lines — including the entire L1–L5 reclear — carry `"level": 6` (the env prefix was fixed at baton spawn). So per-level step/action counts derived from the trace `level` field overcount L6 and undercount L1–L5 replays. Use `recordings/` session boundaries + `logs/harness.log` (`levels completed` transitions) for true per-level segmentation. (`tr87-L2-a2` is NOT affected — it labeled its L1 hand-reclear correctly: 52 lines `level:1`, 42 lines `level:2`.)
  2. **`accounting/ledger.jsonl`compaction erratum (corrected in-place).** Earlier ledger revisions reported 1–2 compactions per baton; these were measurement false-positives (a bare `grep compact_boundary` matched PROTOCOL.md text quoted inside the subagents' own transcripts). Verified via three independent signals (no boundary events, no compaction-summary marker, no input-token discontinuity; peak context ≈26% of the 1M window): **all 7 batons ran with 0 compactions.** Current ledger lines carry the ERRATUM note.
  3. **Replay scripts are documentation, not reproduction.** tr87 randomizes glyph cycle-phases per fresh board, so `solutions/replay/L*.txt` desync on a new session; recovery is a hand-reclear from the live board via the win rule in `solutions/GAME.md`.
  4. **Minor blemishes:** one stray post-clear cursor move (no glyph edit) on the L6 board at the end of the L5 baton; `tr87-L2-a1` ended by external interruption (parent process exit), not a play failure — its knowledge was already crystallized (see O03); no API scorecards were saved (`scorecards/` absent); the `traces/` `--surprised` / `--rejected` flags were under-used by all batons, so surprise-density analyses should be derived from `predictions.jsonl` refuted-verdicts instead.

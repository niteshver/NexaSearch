# pandas.Series.isna#

- Series.isna()[source]#
- Detect missing values. Return a boolean same-sized Series indicating if the values are NA. NA values, such as None or `numpy.NaN` , get mapped to True
values.
Everything else gets mapped to False values. Characters such as empty
strings`''` or`numpy.inf` are not considered NA values.
  - Returns:
    - Series
    - Mask of bool values for each element in Series that indicates whether an element is an NA value.

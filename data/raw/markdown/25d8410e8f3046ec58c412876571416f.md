#   ⟨52⟩ qwen-synth-characters-100-json-test 
A **100-row bench-test slice** of `AbstractPhil/qwen-synth-characters`⟨53⟩ processed end-to-end by the qwen-test-runner **12-process extraction system** : the 11 deterministic specialist vision tasks (`tasks_json`) plus caption→JSON-schema structuring of all three prepared captions (`struct_*`). Built to measure wall-clock, schema conformance, and grounding before scaling to the full 60,847-row set.
> These are **not real people** — every image is diffusion-generated. Rows were additionally **age-gated** with `nateraw/vit-age-classifier` (strict mode: reject expected_age<24 or minor-probability-mass>0.20); each row's `age_audit` records the gate's evidence.
##   ⟨49⟩ Added columns (on top of the source schema)   
| column  | content  |  
| --- | --- |  
| `age_audit`  | JSON — age-gate decision + evidence for this row  |  
| `tasks_json`  | JSON — {task: output} for the 11 deterministic vision tasks  |  
| `tasks_valid`  | JSON — {task: bool} schema validity per task  |  
|  `struct_joycaption` / `struct_qwen35_4b` / `struct_animetimm`  | JSON — the caption structured into the slot-registry schema + scores (schema_valid, grounding_rate, coverage_rate, hallucinations)  |  
| `fused_json`  | JSON — the **FusedScene** : entities (position/depth/saliency + stratified OWNED attributes via mask-containment), relations with continuous offsets, counts, shared basin (uncertain attributions, never guessed), scene + quality blocks  |  
| `prompt_fused`  | the deterministic fused prompt rendered from `fused_json` (counts → entities → relations → basin → scene)  |  
|  `fusion_confidence` / `fusion_s`  | overall fusion confidence scalar / per-row fusion wall-clock  |  
|  `proc_width`, `proc_height`  | processing resolution the vision tasks ran at (coords in `tasks_json` are relative to THIS size, in each task's declared coord_space)  |  
| `specialist_s`  | wall-clock seconds for this row's 11-task extraction  |  
##   ⟨50⟩ Caption structuring quality (Qwen3.5-9B, json_mode, greedy)

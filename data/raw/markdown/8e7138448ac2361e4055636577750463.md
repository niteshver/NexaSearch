# pandas.Period.freq#

- Period.freq#
- Return the frequency object for this Period. The frequency object represents the span of time that this Period covers. It is a DateOffset that defines the interval type (e.g., daily, monthly). See also 
  - `Period.freqstr`
  - Return a string representation of the frequency.
  - `Period.asfreq`
  - Convert Period to desired frequency.
 Examples >>> period = pd.Period('2020-01', freq='M') >>> period.freq <MonthEnd>

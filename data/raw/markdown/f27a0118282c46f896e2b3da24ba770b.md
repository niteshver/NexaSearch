# pandas.HDFStore.info#

- HDFStore.info()[source]#
- Print detailed information on the store. The information includes the file path, class name, and a listing of all stored object keys with their types and shapes. 
  - Returns:
    - str
    - A String containing the python pandas class name, filepath to the HDF5 file and all the object keys along with their respective dataframe shapes.
 See also 
  - `HDFStore.get_storer`
  - Returns the storer object for a key.
 Examples >>> df1 = pd.DataFrame([[1, 2], [3, 4]], columns=["A", "B"]) >>> df2 = pd.DataFrame([[5, 6], [7, 8]], columns=["C", "D"]) >>> store = pd.HDFStore("store.h5", "w") >>> store.put("data1", df1) >>> store.put("data2", df2) >>> print(store.info()) >>> store.close() <class 'pandas.io.pytables.HDFStore'> File path: store.h5 /data1 frame (shape->[2,2]) /data2 frame (shape->[2,2])

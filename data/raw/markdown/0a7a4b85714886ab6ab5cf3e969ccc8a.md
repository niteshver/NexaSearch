# pandas.tseries.offsets.WeekOfMonth.rule_code#

- WeekOfMonth.rule_code#
- Return a string representing the base frequency. This code is used internally to identify the frequency type and includes the week number and weekday information. See also 
  - `tseries.offsets.Hour.rule_code`
  - Returns a string representing the base frequency of ‘h’.
  - `tseries.offsets.Day.rule_code`
  - Returns a string representing the base frequency of ‘D’.
 Examples >>> pd.offsets.Week(5).rule_code 'W' >>> pd.offsets.WeekOfMonth(n=1, week=0, weekday=0).rule_code 'WOM-1MON'

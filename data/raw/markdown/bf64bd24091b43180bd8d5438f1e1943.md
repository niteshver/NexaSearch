#   ⟨159⟩ 🎨 Indian Art Styles Dataset 
A comprehensive image classification dataset covering **34 distinct Indian painting and art styles** with **27,139 images** in total. This dataset is designed for training Vision Transformer (ViT) and CNN-based classifiers to recognize traditional Indian art styles.

##   ⟨154⟩ Dataset Structure 

```
dataset/
├── train/          # Training images organized by style
│   ├── aipan/
│   ├── bengal_school/
│   ├── bhil/
│   └── ... (34 style directories)
└── metadata.csv    # Full manifest with style, source, dimensions, hash, URLs

```

Each image is:
  * Minimum 400×400 pixels (permissive filter to preserve portrait/scroll formats)
  * Sourced from verified museum APIs and cultural archives
  * Deduplicated using file hash + URL checks


##   ⟨155⟩ Data Sources 
Images were collected from:
  * **Wikimedia Commons** (category verification + subcategory depth traversal)
  * **Metropolitan Museum of Art API**
  * **Cleveland Museum of Art API**
  * **Victoria and Albert Museum (V &A) API**
  * **Europeana API**
  * **British Library IIIF**
  * **Rubin Museum**
  * **Web Search fallback** (Google Custom Search / Bing Image Search for minority styles)

  * `legacy`: string-format tool-calling training set

##   ⟨40⟩ Files

  * `train_native.jsonl`: native tool-calling training variant
  * `anchor_native.jsonl`: native anchor variant
  * `eval_scenarios.jsonl`: held-out evaluation set

# pandas.Index.get_indexer_for#

- 
final Index.get_indexer_for(*target* )[source]#
- Guaranteed return of an indexer even when non-unique. This dispatches to get_indexer or get_indexer_non_unique as appropriate. 
  - Parameters:
    - **target** Index
    - An iterable containing the values to be used for computing indexer.
  - Returns:
    - np.ndarray[np.intp]
    - List of indices.
 See also 
  - `Index.get_indexer`
  - Computes indexer and mask for new index given the current index.
  - `Index.get_non_unique`
  - Returns indexer and masks for new index given the current index.
 Examples >>> idx = pd.Index([np.nan, "var1", np.nan]) >>> idx.get_indexer_for([np.nan]) array([0, 2])

#   ⟨46⟩ Underwater Test Enhancement Results 
This private dataset repository stores the packaged outputs of the underwater image enhancement reproduction run dated 2026-07-09.
##   ⟨44⟩ Archive 
  * File: `results/underwater_test_enhance_20260709/underwater_test_enhance_20260709_results.zip`
  * Size: 2,196,977,738 bytes
  * SHA256: `2a68c68a75aa853d8eb7008db3f9ccce647fd349639a9fa4f65d4b812f03041a`
  * Source dataset: `BitStrawber/underwater_test`


The archive contains `outputs/`, `manifests/`, `visual_checks/`, and `run_summary.md`. It excludes the original 26 GB source videos, copied runtime environments, checkpoints, and caches.
##   ⟨45⟩ Methods And Outputs 
The run includes seven configurations across three methods:
  * FA+Net: alpha 0.1
  * LiteEnhanceNet: epoch 99
  * EnDiff: official, 0.2, 0.6, 0.9, and 1.0


Each configuration contains 90 enhanced images, 150 enhanced sampled video frames, and 10 sampled MP4 summaries. The 10 source videos were sampled uniformly at 15 frames each; output MP4 files preserve the original 30 fps and therefore last about 0.5 seconds.
The source dataset has no paired ground truth. These outputs should not be presented as a PSNR/SSIM ranking without an additional evaluation protocol.

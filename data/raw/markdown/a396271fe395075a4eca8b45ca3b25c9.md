#   ⟨150⟩ Banana Variety Classification 
A dataset for variety classification of bananas. The dataset contains raw and augmented versions.  
The raw dataset contains 1,166 images.  
Images per class:
  * Anaji: 209
  * Bichi: 182
  * Champa: 136
  * Deshi: 237
  * Shagor: 239
  * Shobri: 163


The augmented dataset contains 6,000 images.  
Images per class:
  * Anaji: 1,000
  * Bichi: 1,000
  * Champa: 1,000
  * Deshi: 1,000
  * Shagor: 1,000
  * Shobri: 1,000


This dataset is indexed on <https://project-agml.github.io/> as part of the AgML python library.

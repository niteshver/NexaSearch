# pandas.Index.memory_usage#

- 
Index.memory_usage(*deep=False* )[source]#
- Memory usage of the values. 
  - Parameters
    - **deep** bool, default False
    - Introspect the data deeply, interrogate object dtypes for system-level memory consumption.
  - Returns
    - bytes used
 See also 
  - `numpy.ndarray.nbytes`
  - Total bytes consumed by the elements of the array.
 Notes Memory usage does not include memory consumed by elements that are not components of the array if deep=False or if used on PyPy

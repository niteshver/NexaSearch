# pandas.PeriodDtype#

- 
class pandas.PeriodDtype(*freq* )[source]#
- An ExtensionDtype for Period data. **This is not an actual numpy dtype** , but a duck type.
  - Parameters:
    - **freq** str or DateOffset
    - The frequency of this PeriodDtype.
 Attributes `freq`The frequency object of this PeriodDtype. Methods **None**See also 
  - `Period`
  - Represents a single time period.
  - `PeriodIndex`
  - Immutable index for period data.
  - `date_range`
  - Return a fixed frequency DatetimeIndex.
  - `Series`
  - One-dimensional array with axis labels.
  - `DataFrame`
  - Two-dimensional, size-mutable, potentially heterogeneous tabular data.
 Examples >>> pd.PeriodDtype(freq="D") period[D] >>> pd.PeriodDtype(freq=pd.offsets.MonthEnd()) period[M]

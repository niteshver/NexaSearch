# 3DEdit-1M
A large-scale 3D edit-pair dataset of the paper **Omni123: Exploring 3D Native Foundation Models with Limited 3D Data by Unifying Text to 2D and 3D Generation⟨53⟩**.
Each sample is a paired (source, target) 3D edit. The pipeline behind every sample:
  * **Edit instruction** synthesized by Qwen3.5-35B-A3B⟨54⟩.
  * **Target image** (post-edit RGB render) generated by FLUX.2-klein-9b-kv⟨55⟩.
  * **Source and target 3D meshes** generated by Hunyuan3D-2-mini⟨56⟩ from the source and target images.
  * **Shape tokenization** : each mesh is tokenized with the cube3d v0.5⟨57⟩ shape encoder (`OneDAutoEncoder`); the released `.npy` files store those discrete encoder indices.


##   ⟨49⟩ Release status 
  * Partial release — **~524k** edit pairs
  * Full release — **~1M** edit pairs


##   ⟨50⟩ Dataset structure 
The dataset is shipped as WebDataset⟨58⟩-style tar shards under `data/`:

```
data/
├── shard-000000.tar
├── shard-000001.tar
├── ...
└── shard-000135.tar      # 136 shards total

```
  
| File  | Description  |  
| --- | --- |  
| `<id>/<id>.source.npy`  | Source shape token indices from the cube3d v0.5⟨57⟩ encoder — shape `(1, 1024)` `int64`, codebook size 16,384 (value range `[0, 16383]`)  |  
| `<id>/<id>.target.npy`  | Target shape token indices — same encoder, same shape/dtype  |  
| `<id>/<id>.source.rgba.webp`  | Source RGBA render  |  
| `<id>/<id>.target.rgba.webp`  | Target RGBA render  |  
| `<id>/<id>.meta.json`  | Edit instruction and metadata (see below)  |  
###   ⟨51⟩ `meta.json` fields 

```
{
  "id": "<id>",
  "uuid": "<original uuid; for reversed entries, the un-reversed source uuid>",
  "captions": ["long caption ...", "medium caption ...", "short caption"],
  "instruction": "Replace the flintlock mechanism with a modern bolt-action lever."
}

```

**Loading with WebDataset**

```
import webdataset as wds

url = "https://huggingface.co/datasets/OmniWeave/3DEdit-1M/resolve/main/data/shard-{000000..000135}.tar"
ds = (
    wds.WebDataset(url, shardshuffle=True)
    .decode("rgb")
    .to_tuple("source.npy", "target.npy",
              "source.rgba.webp",
              "target.rgba.webp",
              "meta.json")
)

```

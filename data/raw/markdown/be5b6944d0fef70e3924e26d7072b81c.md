#   ⟨63⟩ NASA-EO-Bench 
A large-scale benchmark for **geoscience dataset retrieval** , derived from citation relationships in peer-reviewed NASA publications.
**Paper:** Bringing Agentic Search to Earth Observation Data Discovery⟨64⟩
##   ⟨56⟩ Overview 
Finding the right NASA Earth observation dataset for a given research need is hard even for domain experts. NASA-EO-Bench operationalises this task as an information retrieval problem: given a natural-language query describing a scientific information need, retrieve the relevant datasets from the NASA Common Metadata Repository (CMR) corpus.  
| Split  | Queries  | Query–dataset pairs  |  
| --- | --- | --- |  
| Train  | 17,038  | 38,078  |  
| Test  | 4,234  | 9,576  |  
| **Total**  | **21,272**  | **47,654**  |  
  * **Corpus:** 8,058 NASA CMR datasets, each with `shortName`, `longName`, and abstract
  * **Mean cited datasets per query:** 2.24 (median: 2)
  * To our knowledge, the **first geoscience dataset retrieval benchmark at this scale that supports supervised model training**


##   ⟨57⟩ Construction 
Queries are derived from the NASA Earth Observation Knowledge Graph (NASA EO-KG)⟨65⟩, which links peer-reviewed publications to the NASA CMR datasets they cite.
  1. Select the top 10,636 NASA publications by citation count.
  2. Generate two independent "I want to ..." queries per publication from the paper abstract using GPT-5.4.
  3. Use the datasets explicitly cited by each paper as ground-truth answers.


The train/test split is **publication-level** : both queries from a given publication are in the same split, so no publication appears in both sets. The split is **stratified by citation count** so that the distribution of high- and low-citation papers is matched between train and test, avoiding domain shift across citation tiers.
##   ⟨58⟩ Data Format 
Each record in `train.jsonl` / `test.jsonl` is a JSON object:

```
{
  "id": 0,
  "question": "I want to find global remote sensing and flux-tower datasets of gross primary productivity, evapotranspiration, water-use efficiency...",
  "answer": [
    {
      "globalId": "a29954a1-dc82-5634-986d-f64aa051764a",
      "doi": "10.5067/MODIS/MOD16A2GF.061",
      "shortName": "MOD16A2GF",
      "longName": "MODIS/Terra Net Evapotranspiration Gap-Filled 8-Day L4 Global 500m SIN Grid V061"
    }
  ],
  "cited_by_count": 14,
  "publication_id": "32164"
}

```
  
| Field  | Description  |  
| --- | --- |  
| `id`  | Integer index within the split  |  
| `question`  | Natural-language retrieval query ("I want to ...")  |

##   ⟨60⟩ Evaluation 
The CMR corpus (8,058 datasets) can be queried live via the NASA CMR API⟨66⟩. Standard retrieval metrics against the `answer` field:
  * **GT (ground-truth) Recall@K** — fraction of cited datasets appearing in top-K results
  * **MAP** — mean average precision over the full ranked list
  * **MRR** — mean reciprocal rank


##   ⟨61⟩ Limitations 
  * **Citation ≠ complete relevance.** Ground-truth labels are datasets the source paper _used_ , not all that are applicable. Alternative products on the same topic (e.g. TRMM, IMERG, CMORPH for precipitation) are typically not cited and would count as false positives under citation-based evaluation.
  * **Popular dataset bias.** Citation-grounded evaluation rewards high-visibility datasets (MODIS, Landsat, GPM IMERG) and penalises less-cited alternatives on the same topic.
  * **Corpus scope.** The retrieval corpus covers only the 8,058 NASA CMR datasets present in NASA EO-KG; datasets outside this corpus are not candidates.

# `sklearn.gaussian_process.regression_models`.quadratic¶

- 
`sklearn.gaussian_process.regression_models.``quadratic` (*x* )[source]¶
- Second order polynomial (quadratic, p = n*(n-1)/2+n+1) regression model. 
  - x –> f(x) = [ 1, { x_i, i = 1,...,n }, { x_i * x_j, (i,j) = 1,...,n } ].T
  - i > j
 Parameters: **x** : array_likeAn array with shape (n_eval, n_features) giving the locations x at which the regression model should be evaluated. Returns: **f** : array_likeAn array with shape (n_eval, p) with the values of the regression model.

# pandas.Timestamp.weekday#

- Timestamp.weekday()#
- Return the day of the week represented by the date. Monday == 0 … Sunday == 6. See also 
  - `Timestamp.dayofweek`
  - Return the day of the week with Monday=0, Sunday=6.
  - `Timestamp.isoweekday`
  - Return the day of the week with Monday=1, Sunday=7.
  - `datetime.date.weekday`
  - Equivalent method in datetime module.
 Examples >>> ts = pd.Timestamp('2023-01-01') >>> ts Timestamp('2023-01-01 00:00:00') >>> ts.weekday() 6

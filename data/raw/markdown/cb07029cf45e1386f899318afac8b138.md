# pandas.tseries.offsets.BusinessHour.end#

- BusinessHour.end#
- Return the end time(s) of the business hour. This property returns a tuple of datetime.time objects representing the end times of business hours. See also 
  - `BusinessHour.start`
  - Return the start time(s) of the business hour.
  - `CustomBusinessHour.start`
  - Return the start time(s) of the custom business hour.
 Examples >>> pd.offsets.BusinessHour().end (datetime.time(17, 0),)

    # Title:Multielectron Effects in Sequential Double Ionization with Elliptical Polarization

View PDF HTML (experimental)
            Abstract:Multielectron double ionization with elliptically polarized light is examined theoretically using a classical ensemble method going beyond the single-active-electron approximation. A knee structure in the ion signal is found. Our analysis provides an explanation for newly observed SDI phenomena.

# pandas.api.extensions.ExtensionDtype.construct_from_string#

- 
classmethod ExtensionDtype.construct_from_string(*string* )[source]#
- Construct this type from a string. This is useful mainly for data types that accept parameters. For example, a period dtype accepts a frequency parameter that can be set as `period[h]` (where H means hourly frequency).By default, in the abstract class, just the name of the type is expected. But subclasses can overwrite this method to accept parameters. 
  - Parameters:
    - **string** str
    - The name of the type, for example `category` .
  - Returns:
    - ExtensionDtype
    - Instance of the dtype.
  - Raises:
    - TypeError
    - If a class cannot be constructed from this ‘string’.

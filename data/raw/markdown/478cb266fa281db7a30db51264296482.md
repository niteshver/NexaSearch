# pandas.tseries.offsets.FY5253Quarter.qtr_with_extra_week#

- FY5253Quarter.qtr_with_extra_week#
- Return the quarter number that has the leap or 14 week when needed. In a 52-53 week fiscal year, when a year has 53 weeks, one quarter will have 14 weeks instead of the standard 13 weeks. This property indicates which quarter (1, 2, 3, or 4) receives the extra week. 
  - Returns:
    - int
    - The quarter number (1, 2, 3, or 4) that contains the extra week in 53-week years.
 See also 
  - `FY5253Quarter.get_weeks`
  - Get the number of weeks in each quarter.
  - `FY5253Quarter.year_has_extra_week`
  - Check if a given year has 53 weeks.
 Examples >>> offset = pd.offsets.FY5253Quarter( ... weekday=5, startingMonth=12, qtr_with_extra_week=4 ... ) >>> offset.qtr_with_extra_week 4

# pandas.Interval.mid#

- Interval.mid#
- Return the midpoint of the Interval. The midpoint is the average of the left and right bounds, or equivalently the left bound plus half of `length` .See also 
  - `Interval.left`
  - Return the left bound for the interval.
  - `Interval.right`
  - Return the right bound for the interval.
  - `Interval.length`
  - Return the length of the interval.
 Examples >>> iv = pd.Interval(0, 5) >>> iv.mid 2.5

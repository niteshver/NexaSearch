# pandas.DataFrame.radd#

- 
DataFrame.radd(*other* ,*axis='columns'* ,*level=None* ,*fill_value=None* )[source]#
- Get Addition of dataframe and other, element-wise (binary operator radd). Equivalent to `other + dataframe` , but with support to substitute a
fill_value for missing data in one of the inputs. With reverse version,
add.Among flexible wrappers (add, sub, mul, div, floordiv, mod, pow) to arithmetic operators: +, -, *, /, //, %, **. 
  - Parameters:
    - **other** scalar, sequence, Series, dict or DataFrame
    - Any single or multiple element data structure, or list-like object.
    - **axis** {0 or ‘index’, 1 or ‘columns’}
    - Whether to compare by the index (0 or ‘index’) or columns. (1 or ‘columns’). For Series input, axis to match Series index on.
    - **level** int or label
    - Broadcast across a level, matching Index values on the passed MultiIndex level.
    - **fill_value** float or None, default None
    - Fill existing missing (NaN) values, and any new element needed for successful DataFrame alignment, with this value before computation. If data in both corresponding DataFrame locations is missing the result will be missing.
  - Returns:
    - DataFrame
    - Result of the arithmetic operation.

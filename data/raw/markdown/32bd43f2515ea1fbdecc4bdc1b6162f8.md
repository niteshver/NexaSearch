#   ⟨56⟩ Indonesian Coffee Sentiment & Reviews Dataset 
##   ⟨34⟩ Dataset Description 
Dataset ulasan dan sentimen kopi Indonesia berbahasa Indonesia dengan lebih dari **10,500 sampel** untuk tugas sentiment analysis, text classification, dan aspect-based sentiment analysis (ABSA). Dataset ini dirancang khusus untuk aplikasi NLP pada domain specialty coffee Indonesia.
###   ⟨35⟩ Dataset Summary 
  * **Bahasa** : Indonesian (id)
  * **Jumlah Data** : 10,500 rows
  * **Jumlah Kolom** : 16 columns
  * **Format** : CSV
  * **License** : MIT
  * **Ukuran File** : ~6.8 MB


###   ⟨36⟩ Supported Tasks 
  1. **Sentiment Classification** : Klasifikasi sentimen review (positive, negative, neutral)
  2. **Rating Prediction** : Prediksi rating bintang (1-5)
  3. **Aspect-Based Sentiment Analysis** : Analisis sentimen berbasis aspek (taste, aroma, value, packaging)
  4. **Text Classification** : Klasifikasi produk dan brand kopi


##   ⟨37⟩ Dataset Structure 
###   ⟨38⟩ Data Fields   
| Field  | Type  | Description  |  
| --- | --- | --- |  
| `review_id`  | string  | Unique identifier untuk setiap review (REV000001 - REV010500)  |  
| `product_name`  | string  | Nama produk kopi (18 varietas dari berbagai daerah di Indonesia)  |  
| `brand`  | string  | Nama brand/roastery (17 brand termasuk specialty coffee shops)  |  
| `region`  | string  | Region pembeli/reviewer (12 kota besar di Indonesia)  |  
| `review_text`  | string  | Teks ulasan dalam bahasa Indonesia (100-200 karakter)  |  
| `sentiment`  | string  | Label sentimen: `positive`, `negative`, atau `neutral`  |  
| `rating`  | integer  | Rating bintang (1-5)  |  
| `price_idr`  | integer  | Harga produk dalam Rupiah (30,000 - 500,000)  |  
| `weight_gram`  | integer  | Berat produk dalam gram (100, 200, 250, 500, 1000)  |  
| `roast_level`  | string  | Tingkat roasting: Light, Medium, Medium-Dark, Dark, French Roast  |  
| `processing_method`  | string  | Metode processing: Natural, Washed, Honey, Semi-Washed, Wet-Hulled  |  
| `taste_score`  | integer  | Skor rasa (1-5)  |  
| `aroma_score`  | integer  | Skor aroma (1-5)  |  
| `value_score`  | integer  | Skor value for money (1-5)  |  
| `packaging_score`  | integer  | Skor packaging (1-5)  |  
| `review_date`  | string  | Tanggal review dalam format YYYY-MM-DD (2024-2026)  |  
###   ⟨39⟩ Data Splits 
Dataset ini tidak memiliki split pre-defined. Disarankan untuk membagi menjadi:
  * Train: 70% (7,350 samples)
  * Validation: 15% (1,575 samples)
  * Test: 15% (1,575 samples)

##   ⟨41⟩ Dataset Creation 
###   ⟨42⟩ Source Data 
Dataset ini dibuat secara **synthetic/generated** menggunakan template-based generation dengan variasi vocabulary yang kaya untuk menciptakan ulasan yang realistis dan natural dalam bahasa Indonesia.
###   ⟨43⟩ Data Collection 
  * **Produk** : 18 varietas kopi dari berbagai daerah di Indonesia (Aceh, Gayo, Toraja, Bali, Papua, Flores, Sumatera, Jawa, dll.)
  * **Brand** : 17 brand kopi lokal Indonesia (Anomali, Janji Jiwa, Fore, Filosofi Kopi, Otten, dll.)
  * **Review Templates** : 30+ template ulasan dengan variasi natural language
  * **Flavor Notes** : 12 flavor profiles (chocolate, caramel, fruity, floral, nutty, spicy, citrus, berry, earthy, herbal, vanilla, brown sugar)
  * **Sentiment Distribution** : 
    * Positive: 60% (6,305 reviews)
    * Negative: 20% (2,131 reviews)
    * Neutral: 20% (2,064 reviews)


###   ⟨44⟩ Annotation Process 
Label sentimen dan rating di-generate secara konsisten berdasarkan template review yang digunakan:
  * **Positive reviews** : rating 4-5 bintang
  * **Negative reviews** : rating 1-2 bintang 
  * **Neutral reviews** : rating 3 bintang


Aspect scores (taste, aroma, value, packaging) digenerate dengan korelasi terhadap overall sentiment.
##   ⟨45⟩ Considerations for Using the Data 
###   ⟨46⟩ Social Impact 
Dataset ini bertujuan untuk:
  * Mendukung penelitian NLP untuk bahasa Indonesia
  * Membantu pengembangan sistem sentiment analysis untuk industri F&B Indonesia
  * Menyediakan benchmark untuk aspect-based sentiment analysis


###   ⟨47⟩ Limitations 
  * Data bersifat **synthetic/generated** , bukan ulasan riil dari konsumen
  * Vocabulary dan pola kalimat terbatas pada template yang telah didefinisikan
  * Tidak mencakup semua dialek dan variasi bahasa Indonesia regional
  * Distribusi sentimen mungkin tidak mencerminkan distribusi riil di marketplace


###   ⟨48⟩ Biases 
  * Bias terhadap specialty coffee dibanding kopi instan/mass market
  * Bias geografis terhadap 12 kota besar di Indonesia
  * Sentiment distribution di-balance secara manual (60-20-20)

##   ⟨53⟩ Usage Example 

```
from datasets import load_dataset
import pandas as pd

# Load dataset
dataset = load_dataset("Hadisawara/indonesian-coffee-sentiment-reviews")

# Convert to pandas DataFrame
df = pd.DataFrame(dataset['train'])

# Basic statistics
print(f"Total samples: {len(df)}")
print(f"\nSentiment distribution:\n{df['sentiment'].value_counts()}")
print(f"\nAverage rating: {df['rating'].mean():.2f}")

# Filter positive reviews with high rating
positive_high_rating = df[(df['sentiment'] == 'positive') & (df['rating'] == 5)]
print(f"\nPositive 5-star reviews: {len(positive_high_rating)}")

# Aspect-based analysis
print(f"\nAverage scores:")
print(f"  Taste: {df['taste_score'].mean():.2f}")
print(f"  Aroma: {df['aroma_score'].mean():.2f}")
print(f"  Value: {df['value_score'].mean():.2f}")
print(f"  Packaging: {df['packaging_score'].mean():.2f}")

```

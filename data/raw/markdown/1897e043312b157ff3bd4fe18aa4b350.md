# pandas.Timestamp.dst#

- Timestamp.dst()#
- Return the daylight saving time (DST) adjustment. This method returns the DST adjustment as a datetime.timedelta object if the Timestamp is timezone-aware and DST is applicable. See also 
  - `Timestamp.tz_localize`
  - Localize the Timestamp to a timezone.
  - `Timestamp.tz_convert`
  - Convert timezone-aware Timestamp to another time zone.
 Examples >>> ts = pd.Timestamp('2000-06-01 00:00:00', tz='Europe/Brussels') >>> ts Timestamp('2000-06-01 00:00:00+0200', tz='Europe/Brussels') >>> ts.dst() datetime.timedelta(seconds=3600)

#   ⟨160⟩ ChartQA-PT 
European Portuguese (pt-PT) machine translation of **ChartQA** , a visual question answering dataset that requires reasoning over charts and plots.
Translated from the original English `test` split using **gemini-3.1-pro**.
**Original Dataset:** <https://huggingface.co/datasets/lmms-lab/ChartQA>
**Note:** This dataset is machine translated and may contain translation errors or artifacts.
This dataset is provided as part of the AMALIA project⟨158⟩ and is included in amalia-vl-eval⟨159⟩, a comprehensive benchmark suite for evaluating large vision-language models on European Portuguese.

#   ⟨159⟩ POPE-PT 
European Portuguese (pt-PT) machine translation of **POPE** , a benchmark for evaluating object hallucination in vision-language models through yes/no polling questions.
Translated from the original English `test` split using **gemini-3.1-pro**.
**Original Dataset:** <https://huggingface.co/datasets/lmms-lab/POPE>
**Note:** This dataset is machine translated and may contain translation errors or artifacts.
This dataset is provided as part of the AMALIA project⟨157⟩ and is included in amalia-vl-eval⟨158⟩, a comprehensive benchmark suite for evaluating large vision-language models on European Portuguese.

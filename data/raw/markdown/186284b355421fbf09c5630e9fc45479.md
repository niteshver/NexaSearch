#   ⟨51⟩ D05 
Multimodal industrial-anomaly inspection VQA (multiple-choice; image + question -> option). Category **B** , task **T-B3** , in the unified Smart-Manufacturing SFT schema.
> The repository name is an internal task code. See **Provenance** below for the underlying dataset.
##   ⟨47⟩ Records 
**39,670** records (test=39670). 
##   ⟨48⟩ Unified SFT schema   
| field  | type  | meaning  |  
| --- | --- | --- |  
| `query`  | str  | the question / instruction (model input)  |  
| `image`  | Image  | the input image (bytes embedded)  |  
| `annot`  | str  | the answer — for this dataset: the MCQ gold answer — the bare option letter (e.g. `A`), exactly the native MMAD `Answer`; the option text and question type are in `metadata`  |  
| `reasoning`  | null  | no native CoT in these datasets  |  
| `cate`  | "B"  | SFT category  |  
| `task`  | "T-xx"  | unified task id  |  
| `metadata`  | str (JSON)  | split, provenance, `image_path`, `image_sha256` (dedup key)  |  
| `mask`  | Image | null  |  _(T-B1/T-B2 only)_ the pixel ground-truth mask, bytes embedded  |  
| `masks`  | list[Image]  |  _(D21 only)_ multi-region masks  |  
##   ⟨49⟩ Provenance 
Underlying dataset: **MMAD**. Upstream license: **CC BY-NC-SA 4.0** (this card is `license: other`; respect the upstream terms). Converted read-only from the raw source into the unified schema; conversion script: `D05/convert_d05.py`, published with `publish/push_to_hf.py`, both in `AI4Manufacturing/forge_model`⟨52⟩.
##   ⟨50⟩ Overlap / de-duplication (§8) 
Aggregates MVTec-AD/MVTec-LOCO/VisA/GoodsAD images; dedup via metadata.image_sha256 before any train/eval split. Each record carries `metadata.image_sha256` so overlapping images can be kept entirely on one side of a train/eval split.

# pandas.Index.is_boolean#

- 
*final* Index.is_boolean()[source]#
- Check if the Index only consists of booleans. Deprecated since version 2.0.0: Use pandas.api.types.is_bool_dtype instead. 
  - Returns
    - bool
    - Whether or not the Index only consists of booleans.

#   ⟨54⟩ Chinese-Southeast Asian Monolingual Test Set 
This repository contains a gated monolingual test set for 7 Southeast Asian languages plus a Chinese monolingual test set extracted from unused bilingual-pool target-side text.
Access is gated with manual approval. Users must request access on Hugging Face, and the repository owner must approve the request before files can be downloaded.

##   ⟨53⟩ Selection Rule 
Each Southeast Asian language contains 2,000 monolingual test rows selected from the local monolingual pool. These rows are constrained to 50-100 whitespace-delimited tokens. For Vietnamese, 701 rows were generated as 50-100-token excerpts from longer monolingual rows because only 1,299 existing rows satisfied the length constraint directly.
The Chinese file contains 2,000 target-side Chinese rows sampled from unused rows in the original bilingual high/low pools. Rows already used in the bilingual train or validation files were excluded before sampling.

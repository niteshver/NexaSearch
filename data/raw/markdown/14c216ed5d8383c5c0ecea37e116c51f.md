# pandas.PeriodIndex.start_time#

- property PeriodIndex.start_time[source]#
- Get the Timestamp for the start of the period. This property returns the exact start time of the period as a Timestamp. For example, a monthly period starting in January 2020 would return a Timestamp of ‘2020-01-01 00:00:00’. 
  - Returns:
    - Timestamp
 See also 
  - `Period.end_time`
  - Return the end Timestamp.
  - `Period.dayofyear`
  - Return the day of year.
  - `Period.daysinmonth`
  - Return the days in that month.
  - `Period.dayofweek`
  - Return the day of the week.
 Examples >>> period = pd.Period('2012-1-1', freq='D') >>> period Period('2012-01-01', 'D') >>> period.start_time Timestamp('2012-01-01 00:00:00') >>> period.end_time Timestamp('2012-01-01 23:59:59.999999')

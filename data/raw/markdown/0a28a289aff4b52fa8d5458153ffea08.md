#   ⟨101⟩ CELLDS-Lysosomes (Curated Subcellular Dataset) 
This dataset contains high-resolution fluorescence microscopy images designed for the development and benchmarking of cell and lysosome segmentation algorithms.
##   ⟨100⟩ Dataset Structure 
  * 📁 **`raw_images_w1/`**: Nuclei channel (DAPI/Hoechst)
  * 📁 **`raw_images_w2/`**: Lysosomes channel (LysoTracker/LAMP1)
  * 📁 **`raw_images_w3/`**: Cytoplasm/Whole Cell channel
  * 📁 **`cell_masks/`**: Instance cell segmentation masks (generated by Cellpose)
  * 📁 **`lysosome_masks/`**: Hand-curated 16-bit instance segmentation masks for lysosomes (Fiji curated)


This dataset currently contains the first 12 curated image sets from the 25-image curation batch.

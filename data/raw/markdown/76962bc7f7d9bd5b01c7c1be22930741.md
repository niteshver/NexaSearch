# pandas.Series.str.isalpha#

- Series.str.isalpha()[source]#
- Check whether all characters in each string are alphabetic. This is equivalent to running the Python string method `str.isalpha()` for each element of the Series/Index. If a string
has zero characters,`False` is returned for that check.
  - Returns:
    - Series or Index of bool
    - Series or Index of boolean values with the same length as the original Series/Index.

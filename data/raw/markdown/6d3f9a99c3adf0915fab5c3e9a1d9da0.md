# pandas.Timedelta.microseconds#

- Timedelta.microseconds#
- Return the number of microseconds (n), where 0 <= n < 1 millisecond. Timedelta.microseconds = milliseconds * 1000 + microseconds. 
  - Returns:
    - int
    - Number of microseconds.
 See also 
  - `Timedelta.components`
  - Return all attributes with assigned values (i.e. days, hours, minutes, seconds, milliseconds, microseconds, nanoseconds).
 Examples **Using string input**>>> td = pd.Timedelta('1 days 2 min 3 us') >>> td.microseconds 3 **Using integer input**>>> td = pd.Timedelta(42, unit='us') >>> td.microseconds 42

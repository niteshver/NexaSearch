#   ⟨52⟩ RepoZero-C2Rust 
 ![RepoZero](https://huggingface.co/datasets/PKU-Wu-Lab/RepoZero-C2Rust/resolve/main/icon_repozero.png) ⟨53⟩
![arXiv](https://img.shields.io/badge/RepoZero-arxiv-red)⟨54⟩ ![code](https://img.shields.io/badge/github-repo-blue?logo=github)⟨53⟩ ![HuggingFace-C2Rust](https://img.shields.io/badge/C2Rust-HF-yellow?logo=huggingface)⟨55⟩ ![HuggingFace-Py2JS](https://img.shields.io/badge/Py2JS-HF-yellow?logo=huggingface)⟨56⟩ ![Project Page](https://img.shields.io/badge/Homepage-gray?logo=homepage)⟨57⟩
RepoZero-C2Rust is a benchmark subset for evaluating **zero-shot C++ to Rust repository-level code translation**.
##   ⟨39⟩ Overview   
| Property  | Value  |  
| --- | --- |  
| **Source Language**  | C++  |  
| **Target Language**  | Rust  |  
| **Number of Libraries**  | 11  |  
| **Total Test Files**  | 200  |  
| **HuggingFace Dataset**  | jessezhaoxizhang/RepoZero-C2Rust⟨28⟩  |  
##   ⟨40⟩ Task Description 
Given a C++ library implementation, the model must translate it into idiomatic, correct Rust code that:
  * Re-implements the library logic using Rust-native idioms and standard crates
  * Matches the I/O behavior of the original C++ test programs exactly
  * Avoids directly wrapping the C++ source (zero-shot black-box translation)

##   ⟨43⟩ Data Format 
###   ⟨44⟩ Source Files 
Each library in `CppLarge/` contains:
  * C++ source files (`.cpp`, `.hpp`)
  * Pre-compiled test executables
  * Test input files


###   ⟨45⟩ Test Cases 
`cleaned_test_cases.jsonl` contains test case parameters in JSONL format:

```
{"filename": "Clipper/test1", "input": "...", "expected_output": "..."}

```

##   ⟨48⟩ Docker Environment 
Each evaluation task runs in an isolated container with:
  * **Workspace** : `/workspace`
  * **Dataset** : `/workspace/dataset` (C++ sources + pre-compiled executables)
  * **Output** : `/output` (generated Rust files)
  * **Rust Toolchain** : Latest stable Rust with cargo
  * **Network** : Disabled (`--network none`) for security

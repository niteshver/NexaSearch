#   ⟨53⟩ Primary Maths Manim Instruction Dataset 
This is a synthetic and model-repair instruction-tuning dataset for training coding models to generate **Manim Community Edition Python code** for primary-school mathematics animation videos.
The current final dataset contains **6,023 chat-formatted examples** covering:
  * Fractions
  * Place Value
  * Multiplication and Division


It is designed for fine-tuning models such as **Qwen2.5-Coder-Instruct** to produce:
  * executable Manim animation code
  * simple maths storyboards
  * Manim code from storyboards
  * corrected Manim code from broken or weak examples
  * fixed code from Manim/Python error messages
  * improved outputs that better follow layout, duration, font, visual-model, exact-count, and render-error instructions

```
{
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "..."},
    {"role": "assistant", "content": "..."}
  ]
}
```

The ShareGPT/Unsloth version uses `conversations` format:

```
{
  "conversations": [
    {"from": "system", "value": "..."},
    {"from": "human", "value": "..."},
    {"from": "gpt", "value": "..."}
  ]
}

```

The assistant responses contain either complete Manim Python code, a numbered storyboard, or corrected Manim code, depending on the task.

##   ⟨50⟩ Validation 
The dataset was checked for:
  * valid JSONL formatting
  * correct chat message structure
  * unique chat prompts and outputs in generated repair blocks
  * `from manim import *` in code outputs
  * exactly one `Scene` class in code outputs
  * no external assets
  * Python syntax validity
  * explicit timing patterns in duration-repair examples
  * no fake Manim API tokens in corrected targeted-repair outputs


The original **2,295 foundation Manim code outputs** were rendered successfully with Manim Community Edition using Docker.
The latest 800-example targeted Manim error repair add-on passed static validation:
  * 800 valid rows
  * 800 unique IDs
  * 0 duplicate chat prompts
  * 0 duplicate outputs
  * all corrected code outputs parse as Python
  * all corrected code outputs define exactly one `Scene`
  * all corrected code outputs start with `from manim import *`
  * all corrected code outputs include explicit `run_time` pacing
  * no external assets
  * no known fake API tokens in corrected outputs

The full merged dataset was assembled from validated source blocks. Some animations may still benefit from human visual review for polish and pedagogy, even when the code renders successfully.
##   ⟨51⟩ Intended Use 
This dataset is intended for supervised fine-tuning of coding or instruction-following models to improve performance on primary-school maths animation generation using Manim.
It is especially suited for models that need to generate visual educational content from natural-language teacher prompts and revise flawed Manim outputs.
Recommended training use cases:
  * fine-tuning Qwen2.5-Coder-Instruct-style models
  * training Manim code generation behavior
  * improving instruction following for visual constraints
  * teaching model repair from Manim render errors
  * improving exact object counts for arrays, groups, fractions, and place-value charts
  * reducing hallucinated Manim APIs
  * collecting future preference data from generated outputs


##   ⟨52⟩ Limitations 
This dataset is mostly synthetic, with a smaller set of real model-generation repair examples. Although the code was validated for syntax and sampled for rendering, some animations may still require human review for visual polish, pedagogy, or exact classroom suitability.
The dataset is focused on primary-school fractions, place value, multiplication, and division. It should not be assumed to generalize strongly to unrelated subjects without additional training data.

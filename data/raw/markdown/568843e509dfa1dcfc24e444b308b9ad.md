##   ⟨39⟩ Instructions for Dataset 
Due to the single file upload limit, we sharded the dataset into 8 zip files. To use the dataset, we first download them using the GUI or use `git`:

```
# git lfs install (optional)
git clone git@hf.co:datasets/mlfu7/Touch-Vision-Language-Dataset

# There's an improved version of this dataset, which fixed the tactile/image folder swapping issue. 
git clone git@hf.co:datasets/yoorhim/TVL-revise

cd Touch-Vision-Language-Dataset
zip -s0 tvl_dataset_sharded.zip --out tvl_dataset.zip
unzip tvl_dataset.zip 

```

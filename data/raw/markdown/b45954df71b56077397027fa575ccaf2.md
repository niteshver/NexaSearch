# pandas.Index.is_monotonic_increasing#

- property Index.is_monotonic_increasing[source]#
- Return a boolean if the values are equal or increasing. A monotonically increasing index has values that are equal to or greater than the preceding value. This is useful for checking if an index is sorted in non-decreasing order. 
  - Returns:
    - bool
 See also 
  - `Index.is_monotonic_decreasing`
  - Check if the values are equal or decreasing.
 Examples >>> pd.Index([1, 2, 3]).is_monotonic_increasing True >>> pd.Index([1, 2, 2]).is_monotonic_increasing True >>> pd.Index([1, 3, 2]).is_monotonic_increasing False

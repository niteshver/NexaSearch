#   ⟨58⟩ D05 Annotated — the full MMAD chain-of-thought corpus 
The complete reasoning-augmented version of `AI4Manufacturing/D05`⟨59⟩ (MMAD, multimodal industrial anomaly-detection MCQ): **34,414 records** , every one with a teacher-written **chain-of-thought** ending in `FINAL ANSWER`. This is the **merge of two tracks** that were built (and are also released) separately, because they make different claims about the answer:  
| Track  | Records  | Answer (`annot`)  | Also released as  |  
| --- | --- | --- | --- |  
| **Track 1 — rationalized**  | 31,405  | the **original MMAD gold** (reliable, source-derived) — unchanged for all but 19 adjudicated records (see fix package below; 4 of those use `answer: null`)  | `D05-1-annotated`⟨60⟩  |  
| **Track 2a — re-solved**  | 3,009  |  **teacher-corrected** : the teacher independently re-identified the defect and could reject the MMAD label (605 changed, 75 reject all options → `answer: null`)  | `D05-2a-annotated`⟨61⟩  |  
Track 1 covers the question types whose MMAD golds are reliable (Anomaly Detection, Defect Localization / Description, Object Classification / Analysis / Structure / Details, and Defect Classification on DS-MVTec). Track 2a covers Defect Classification on the _label-poor_ sources (VisA, PKU-GoodsAD, MVTec-LOCO), where MMAD's answers were model-assigned and frequently wrong. The under-determined "Defect Analysis" type is excluded, as are 474 Track-2a records that failed the correctness gate.
**Filter by track** with `metadata.cot.source`: `"D05_track1_rationalized"` vs `"D05_track2a_resolve"`.
##   ⟨52⟩ Schema   
| field  | description  |  
| --- | --- |  
| `query`  | the original MMAD multiple-choice question (directive updated to "Answer with the option content." — see fix package below)  |  
| `image`  | the test image (HF `Image`, unchanged)  |  
| `annot`  |  `{answer, answer_text, question_type}` — original gold (Track 1) or corrected (Track 2a; see above)  |  
| `reasoning`  | teacher chain-of-thought, grounded only in the test image, ending `FINAL ANSWER: …`  |  
|  `cate` / `task`  | unchanged from the base dataset  |  
| `metadata`  | original MMAD metadata + a `cot` provenance block: annotator model, method (`rationalized` / `rationalized_regenerated` / `re_solved_gold_corrected`), the faithfulness screen/gate verdict, any regeneration record, and for Track 2a the original MMAD gold  |  
##   ⟨53⟩ Roles 
**Roles:** `reasoning` is the SFT imitation target — its `FINAL ANSWER` segment is the model-facing answer format; `annot` is the machine-parseable gold used for verification and reward parsing, **not** an output-format target.
##   ⟨54⟩ How it was built 
  * **Track 1 (gold-conditioned, improve-never-drop):** gpt-5-mini wrote reasoning justifying the reliable gold, grounded teacher-side by a defect-free reference image (+ segmentation mask for defect subtypes) that is **never leaked** into the text. Every CoT was screened for faithfulness (Claude Sonnet 5); flagged over-reads were **regenerated** with the critique fed back and replaced only when clearly better. Nothing dropped; ~87% of CoTs score faithfulness ≥ 3, the residual is documented per-record.
  * **Track 2a (re-solved):** Claude Opus 4.8 independently determined the defect (free to reject the proposed label); an independent judge gated answer correctness; failures were dropped.
  * Both tracks are leak-audited (no references to the reference image / mask / provided answer).


##   ⟨55⟩ 2026-07-18 fix package 
The data files were revised in place. This merged corpus inherits the fix packages of both tracks — **29 corrected records in total** (19 Track-1 + 10 Track-2a) and **79 null-answer records** (4 Track-1 + 75 Track-2a):
  * **Query directive (both tracks).** The MCQ instruction now reads **"Answer with the option content."** — previously it asked for the option letter, contradicting the answer format actually used by `reasoning` / `FINAL ANSWER`.
  * **FINAL canonicalization.** All 3,009 Track-2a `reasoning` fields now end with a canonical `FINAL ANSWER: <answer_text>` line.
  * **Track-1 MMAD-gold adjudication: 19 records'`annot` corrected.** An adjudication pass (unconditioned **claude-opus-4-8 re-solve** + independent **claude-sonnet-4-6 gate**) overturned the original MMAD gold on all 19; corrections were **operator-verified visually on all distinct case types**. Each carries `metadata.cot.original_mmad_gold` plus the full adjudication verdict. **10 of the 19 are a systematic mirrored-gold defect in VisA`pcb4`** (micro-USB position golds on the wrong side) — an upstream MMAD/VisA issue. **4 of the 19** use the null convention (`answer: null` — no offered option is true).
  * **Track-2a answer-matcher bug.** **10 records'`annot` corrected** for a fuzzy answer-matcher bug (fix + hard assert now in the pipeline); per-record provenance in `metadata.cot.annot_correction` with `original_annot`.
  * **Gate visibility (Track 2a).** **249 records carry`metadata.cot.gate.keep = false`** — retained under improve-never-drop. Filter recipe for strict training: drop rows where `gate.keep` is `false`.


Counts verified by the corpus contradiction re-scan (0 contradictions, 2026-07-18).
##   ⟨56⟩ Intended use & caveats 
  * For **non-commercial research** on manufacturing-domain vision-language reasoning (CC-BY-NC-SA-4.0, inherited from MMAD).
  * `reasoning` is **teacher-generated and model-gated** , not human-verified. Track-2a answers are model-corrected; the original MMAD gold is always retained in `metadata.cot.original_mmad_gold`. Track-1 answers are the original MMAD golds, except for the 19 adjudicated records disclosed in the fix package above (each retains `metadata.cot.original_mmad_gold`).
  * The two track repos remain available for consumers who want only one claim type.

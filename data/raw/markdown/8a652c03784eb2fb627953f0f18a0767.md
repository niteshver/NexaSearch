# pandas.api.typing.DataFrameGroupBy.plot#

- property DataFrameGroupBy.plot[source]#
- Make plots of groups from a DataFrame. Uses the backend specified by the option `plotting.backend` .
By default, matplotlib is used.
  - Returns:
    - GroupByPlot
    - A plotting object that can be used to create plots for each group.
 See also 
  - `DataFrame.plot`
  - Make plots of DataFrame.
 Examples >>> df = pd.DataFrame( ... {"A": [1, 2, 3, 4], "B": [5, 6, 7, 8]}, index=["a", "a", "b", "b"] ... ) >>> g = df.groupby(level=0) >>> g.plot()

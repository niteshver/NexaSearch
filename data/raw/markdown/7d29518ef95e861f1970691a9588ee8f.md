# pandas.Series.str.islower#

- Series.str.islower()[source]#
- Check whether all characters in each string are lowercase. This is equivalent to running the Python string method `str.islower()` for each element of the Series/Index. If a string
has zero characters,`False` is returned for that check.
  - Returns:
    - Series or Index of bool
    - Series or Index of boolean values with the same length as the original Series/Index.
 See also

  - Check whether all characters are alphabetic.
  - `Series.str.isnumeric`
  - Check whether all characters are numeric.
  - `Series.str.isalnum`
  - Check whether all characters are alphanumeric.
  - `Series.str.isdigit`
  - Check whether all characters are digits.
  - `Series.str.isdecimal`
  - Check whether all characters are decimal.
  - `Series.str.isspace`
  - Check whether all characters are whitespace.
  - `Series.str.isascii`
  - Check whether all characters are ascii.
  - `Series.str.isupper`
  - Check whether all characters are uppercase.
  - `Series.str.istitle`
  - Check whether all characters are titlecase.

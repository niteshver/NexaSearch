#   ⟨58⟩ BundleDex — OKF Bundle Directory Dataset 
A curated directory of **249 Open Knowledge Format (OKF) bundles** for AI agents and knowledge systems. Each entry represents a GitHub repository that publishes OKF-formatted knowledge.
##   ⟨54⟩ Dataset Structure 
Each row is a bundle with:  
| Field  | Type  | Description  |  
| --- | --- | --- |  
| `slug`  | string  | Unique identifier  |  
| `name`  | string  | Human-readable name  |  
| `description`  | string  | What the bundle covers  |  
| `author`  | string  | GitHub author/owner  |  
| `stars`  | integer  | GitHub stars (quality signal)  |  
| `tags`  | list[string]  | Topic tags  |  
| `category`  | string  | Content category (e.g. "AI & ML", "Tooling")  |  
| `repo_url`  | string  | Source repository  |  
| `okf_url`  | string  | OKF manifest (agent-parseable)  |  
| `license`  | string  | Repository license  |

# pandas.api.typing.DataFrameGroupBy.prod#

- 
DataFrameGroupBy.prod(*numeric_only=False* ,*min_count=0* ,*skipna=True* )[source]#
- Compute prod of group values. This method computes the product of all values within each group, returning a result for each group. 
  - Parameters:
    - **numeric_only** bool, default False
    - Include only float, int, boolean columns. Changed in version 2.0.0: numeric_only no longer accepts `None` .
    - **min_count** int, default 0
    - The required number of valid values to perform the operation. If fewer than `min_count` non-NA values are present the result will be NA.
    - **skipna** bool, default True
    - Exclude NA/null values. If an entire group is NA, the result will be NA. Added in version 3.0.0.
  - Returns:
    - Series or DataFrame
    - Computed prod of values within each group.
 See also 
  - `Series.prod`
  - Return the product of the values over the requested axis.

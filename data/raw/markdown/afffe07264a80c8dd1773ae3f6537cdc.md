# pandas.Series.shape#

- property Series.shape[source]#
- Return a tuple of the shape of the underlying data. For a Series this is `(length,)` ; for a 1D Index, likewise a
single-element tuple. Useful for compatibility with NumPy and
other array-like APIs.See also 
  - `Series.ndim`
  - Number of dimensions of the underlying data.
  - `Series.size`
  - Return the number of elements in the underlying data.
  - `Series.nbytes`
  - Return the number of bytes in the underlying data.
 Examples >>> s = pd.Series([1, 2, 3]) >>> s.shape (3,)

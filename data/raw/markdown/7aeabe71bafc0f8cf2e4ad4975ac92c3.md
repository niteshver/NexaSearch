*class* `sklearn.cross_validation.``LeaveOneOut` (*n* ,*indices=None* )[source]¶
- Leave-One-Out cross validation iterator. Provides train/test indices to split data in train test sets. Each sample is used once as a test set (singleton) while the remaining samples form the training set. Note: `LeaveOneOut(n)` is equivalent to`KFold(n, n_folds=n)` and`LeavePOut(n, p=1)` .Due to the high number of test sets (which is the same as the number of samples) this cross validation method can be very costly. For large datasets one should favor KFold, StratifiedKFold or ShuffleSplit. Parameters: **n** : intTotal number of elements in dataset.

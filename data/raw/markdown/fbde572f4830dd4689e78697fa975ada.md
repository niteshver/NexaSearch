# pandas.lreshape#

- 
pandas.lreshape(*data* ,*groups* ,*dropna=True* )[source]#
- Reshape wide-format data to long. Generalized inverse of DataFrame.pivot. Accepts a dictionary, `groups` , in which each key is a new column name
and each value is a list of old column names that will be “melted” under
the new column name as part of the reshape.
  - Parameters:
    - **data** DataFrame
    - The wide-format DataFrame.
    - **groups** dict
    - {new_name : list_of_columns}.
    - **dropna** bool, default True
    - Do not include columns whose entries are all NaN.
  - Returns:
    - DataFrame
    - Reshaped DataFrame.
 See also 
  - `melt`
  - Unpivot a DataFrame from wide to long format, optionally leaving identifiers set.
  - `pivot`
  - Create a spreadsheet-style pivot table as a DataFrame.

  - Pivot without aggregation that can handle non-numeric data.
  - `DataFrame.pivot_table`
  - Generalization of pivot that can handle duplicate values for one index/column pair.

  - Pivot based on the index values instead of a column.

  - Wide panel to long format. Less flexible but more user-friendly than melt.

# pandas.CategoricalDtype.categories#

- property CategoricalDtype.categories[source]#
- An `Index` containing the unique categories allowed.See also 
  - `ordered`
  - Whether the categories have an ordered relationship.
 Examples >>> cat_type = pd.CategoricalDtype(categories=["a", "b"], ordered=True) >>> cat_type.categories Index(['a', 'b'], dtype='str')

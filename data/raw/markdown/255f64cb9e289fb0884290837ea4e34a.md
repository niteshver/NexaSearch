# pandas.api.typing.SeriesGroupBy.first#

- 
SeriesGroupBy.first(*numeric_only=False* ,*min_count=-1* ,*skipna=True* )[source]#
- Compute the first entry of each column within each group. NA values are skipped by default, so the result is the first non-NA value per column — which may differ from the first row of the group. Pass `skipna=False` to keep NAs.
  - Parameters:
    - **numeric_only** bool, default False
    - Include only float, int, boolean columns.
    - **min_count** int, default -1
    - The required number of valid values to perform the operation. If fewer than `min_count` valid values are present the result will be NA.
    - **skipna** bool, default True
    - Exclude NA values. If an entire group is NA, the result will be NA. Added in version 2.2.1.
  - Returns:
    - Series or DataFrame
    - First values within each group.
